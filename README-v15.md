# 五行纪 · 万灵觉醒 V15

正式游玩：https://dragonking888866.github.io/5elements/?v=15.0.0

独立体验场：https://dragonking888866.github.io/5elements/sandbox.html?v=15.0.0

## 快速试玩

1. 打开独立体验场，点顶栏「测试工具」。电脑也可用键盘反引号键打开、收起工具。
2. 点「开启开发者体验」，再点「最高火龙」。最高品质沿用现有名称「极其稀有」，对应本次任务书的至尊级。
3. 点「终极龙息」观看完整蓄力、喷发、命中与余焰。可选「烈焰风暴」测试旋转演出。
4. 「定格喷发」会实际推进模拟到命中后暂停世界，方便查看；点「恢复动画」继续。重置和关闭开发者也会解除定格。
5. 需要试装备、融合和转职时，打开无限资源，领取宝石/装备/灵宠。点「返回营地」进入原有商店、冶金铺和合成铺；「试炼木桩」回到专用场地。营地返回仍沿用卷轴规则，材料补满会补充卷轴。
6. 试炼木桩无攻击、无掉落。正式远征仍使用原有角色、章节、资源谷和首领规则。

手机推荐横屏；360px 窄屏工具按两列排列，其余主要手机尺寸为三列，按钮至少44px。工具面板可滚动；右上角固定关闭按钮随时返回战场。测试场顶栏保留明确的正式远征链接。

## 本次实现

- 七种品质、灵宠等级与英雄觉醒共同控制技能规模、前摇、持续时间、体型和品质符文。
- 火系：嘴部锚点、连续分层火柱、翻滚火舌、热核、火星、烟尘、命中爆燃与地面余焰。高级演出会短暂明显扩大。
- 雷系：连续曲折闪电及实际命中目标之间的链状电弧；水系：寒雾、晶体和冰棱；木系：藤蔓与飞叶；土系：岩刺、碎石和裂地；金系：剑雨和金属碎光。雷电是现有五行属性下的视觉子类型，不另建第六种相克属性。
- 仍由原有命中队列进行真实伤害结算。改动演出前摇以匹配蓄力动作，未增加原有技能伤害倍率、真实范围或缩短正常冷却。
- 可选择流畅/均衡/绚丽/极高四档、45%/70%/100%演出规模、35%/55%/75%透明度；震动和强闪光可独立关闭，强闪光默认关闭。
- 手机最多1个、电脑最多2个完整大型演出；其余大型施法者按20%规模、流畅细节绘制。演出对象池最多20个，离开可见范围会跳过绘制。
- 150级最高品质火系的演出包围范围基准为视野面积的24.5%，传说约15.8%、神话约20.5%；竖屏上限14%。这些是几何范围配置，并非精确不透明像素占比；实际画面取决于火舌形状、透明度、方向和镜头裁切。
- 正式主界面、手机全选/单选/撤退、五章救援、低风险资源谷、后期首领预警与伤害上限全部保留。

## 指令

指令在独立体验场生效，默认关闭。输入框的执行按钮与回车均可执行。

| 指令 | 作用 |
|---|---|
| `/dev on` / `/dev off` | 开启；关闭并清除资源、无敌、冷却、融合概率特权 |
| `/gold max` | 金币补到现有有限上限 |
| `/gold add 1000000` | 增加100万金币；参数限合法正整数 |
| `/resources max` | 补充金币、灵铁、药剂、卷轴和全部宝石样本 |
| `/resources infinite on` / `off` | 免除相关交易中的金币与材料消耗；关闭后立即恢复 |
| `/gems all` / `/gem max` | 全部类型1—11级样本；或全部最高级样本 |
| `/materials max` | 补满现有灵铁、药剂与卷轴 |
| `/equipment all` | 42件、7品质×6部位的合法测试装备 |
| `/level max` | 当前选中成员达到各自现有等级上限 |
| `/rebirth max` | 当前选中成员设为5次转职、250级，填入真实成长字段 |
| `/pet legendary` / `mythic` / `supreme` | 生成并装备传说/神话/最高品质火龙 |
| `/pet supreme ice` | 同样支持 fire / lightning / wood / earth / metal |
| `/pet all` | 补齐103种现有灵宠，仍受1000容量限制 |
| `/skills unlock` | 解锁选中英雄的有效技能字段 |
| `/god on` / `off` | 无敌测试开关 |
| `/cooldown off` / `on` | 关闭/恢复技能冷却 |
| `/fusion chance 100` / `/fusion reset` | 临时100%融合/恢复真实概率 |
| `/pet skill test` | 在专用试炼场使用实际灵宠技能 |
| `/pet skill fire_breath` | 火系龙息演出 |
| `/pet skill flame_storm` | 火系旋转风暴演出；伤害仍用原技能结算 |
| `/pet skill ultimate` | 最高品质灵宠终极演出 |
| `/fx snapshot` / `/fx resume` | 通过真实模拟定格命中/继续动画 |
| `/camp` / `/arena` | 返回营地/试炼木桩 |
| `/status` / `/help` | 实际体验状态/指令帮助 |

无限资源由独立标记控制，正式余额一直是有限数值。交易期间只在临时钱包内做费用检查，保存前恢复真实余额。宝石融合、镶嵌、灵宠融合、装备打造/淬炼、转职与购买仍执行品质、等级、槽位、配方、容量、重复请求等非资源验证。无限灵宠融合保留两个材料宠并新增结果，因此满1000时拒绝；普通模式继续沿用原消耗规则。无冷却不跳过正在执行的动作、合法目标和法力要求。

## 存档和隔离

正式运行包没有开发者指令执行器。正式存档自动兼容V14及此前支持的版本，使用V15键保存；浏览器缓存升级不会删除旧存档。

体验场在不授予同源权限的 sandbox iframe 内运行，帧内使用内存存储替身。父页面仅桥接一个固定测试键 `wuxing-isolated-lab-v15`，核对消息来源窗口、opaque origin 与本次会话nonce。它不枚举、不读取正式存档键。

测试根存档及测试道具带专用标记。正式导入验证拒绝测试根、英雄、灵宠、装备、宝石、镶嵌和灵台标记。体验操作记录保留最近60条，可导出体验档或重置体验世界。首次打开体验场需网络加载资源。

这是本地单人网页游戏，隔离旨在防止正常操作混用存档；不宣称浏览器客户端具备不可破解的权限控制。没有多人服务端，也没有管理员认证。未来联机必须由服务端验证身份、资产和命令权限，不能把这里的前端开关当作管理员认证。

## 工程和构建

源码包本地结构为 `web/` 与 `tests/`。GitHub Pages 仓库部署时网页文件放仓库根目录，构建和测试路径已按部署结构调整。

```powershell
node build.cjs
node tests/integration.cjs
```

完全禁用体验场构建：

```powershell
$env:WUXING_BUILD_SANDBOX = '0'
node build.cjs
```

该配置隐藏正式菜单入口，将体验页面和运行包替换成禁用占位文件；正式运行包始终不含指令执行器。恢复默认构建前清除该环境变量。

主要修改文件：

| 文件 | 内容 |
|---|---|
| `web/pet-effects-v15.js` | 品质/等级特效、嘴部锚点、元素演出、预算、对象池和设置 |
| `web/motion-v11.js` | 原有真实命中队列增加嘴部及命中反馈钩子 |
| `web/release-v15.js` | 测试数据导入拒绝、版本和独立体验入口 |
| `web/developer-sandbox15.js` | 沙盒专用指令、有限资源事务适配、木桩和工具UI |
| `web/sandbox-host15.js` | 固定测试存档键与隔离帧桥接 |
| `web/sandbox-shim15.js` | 隔离帧内存存储替身 |
| `web/sandbox-shell15.html` | 独立入口和手机安全区域 |
| `web/awakening-v15.css` | 新特效设置、手机工具面板样式 |
| `build.cjs` | 正式/沙盒分包与禁用构建 |
| `tests/effects-sandbox-v15.cjs` | 25项新增回归与交互检查 |

`runtime.js`、`runtime-sandbox.js`、`sandbox-frame.html`和`sandbox.html`由构建生成。`index.html`、`game.js`、`sw.js`及下载说明更新到V15。

# 五行战记 V39 · 神兽天象

正式入口：https://dragonking888866.github.io/5elements/?v=39.0.0

继续原存档。电脑按 **V** 释放灵兽技；手机点 **更多战斗操作 → 灵兽技**。菜单中的画质设置可以调整精细度、透明度和演出规模；低帧率保护默认开启。减少动态效果沿用原设置。

V39 为当前 Canvas 2.5D 引擎新增四个模块：`pet-director-v39.js`（十一套演出与七品质时间轴）、`pet-surfaces-v39.js`（序列纹理、画布池与预算）、`pet-spectacles-v39.js`（不同技能主体）、`pet-compositor-v39.js`（实时口部挂点、缓存合成、角色保护与覆盖率采样）。正式版和体验版使用相同模块。

新增九张原创透明 4×4 动画序列，分别表现龙炎、海潮、冰壁、风柱、金爪、古钟、神木、山岳和混沌裂界。序列纹理与程序化喷流、古藤、羽焰、岩柱、音波、残留裂纹和原有灵兽动态精灵组合，未更换游戏引擎。完整提示词、尺寸、透明通道和 SHA256 记录见 `AI-PROMPTS-v39.json`、`AI-ASSETS-v39.json`。采用内置 imagegen 生成原创资源，原生成文件保留，游戏使用项目内副本。

七品质真实技能半径继续为 **48 / 72 / 104 / 148 / 205 / 280 / 360** 世界单位，祖兽为最高档的 1.1 倍；本版扩大的是视觉演出。冷却、伤害、治疗、护盾、削甲、控制和灼烧仍使用 V38 结算。究极池仍只有十种，混沌祖兽保持独立隐藏获取途径，物品与存档 ID 不变。

本地构建：`node build.cjs`。完整回归：`node tests/release-v39.cjs`。

真实浏览器验收：`python tests/ui/serve39.py`，打开 `http://127.0.0.1:8739/qa.html`。工具仅允许该隔离来源，使用本机虚构进度，不读取正式网站玩家存档。静态关键帧明确重绘，性能场景保持正常帧率限制器。截图、连续关键帧、实战录屏及原始测量 JSON 见 `验收/`；测试方法与限制见 `V39验收报告.md`。

本版使用 2.5D 多层合成与动画序列实现体积观感，没有真实流体、3D 体积模拟或 GPU 后处理。不能以本机浏览器模拟代替真实手机测试。

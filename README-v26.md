# 五行战记 V26 · 灵契星辉：宝石资产与英雄管理中心

直接游玩：https://dragonking888866.github.io/5elements/?v=26.0.0

## 怎么使用

- 点击主画面角色头像，打开英雄中心；上方可直接切换五位已解封英雄。
- “角色”看动态英雄、当前装备、骑乘/随行灵宠、三大属性与完整实战数值；“加点”“天赋”“转职”保留原有成长操作。
- “装备”点击具体装备，查看两个实际宝石孔；觉醒灵台保留五次转职各加一槽的原规则。
- “宝石”默认查看全部资产；支持可用、已镶嵌、已锁定、神石/特殊筛选，以及品质和名称搜索。已镶嵌页显示英雄、装备和具体孔位。
- 点击宝石查看全部属性、唯一ID、归属、锁定与收藏。可直接定位装备、免费拆卸；装备库和待领取装备中的宝石也能直接拆回。
- 点击空孔或“镶嵌/替换/拆卸”，选择可用宝石，预览真实属性变化后确认；旧石原身份返还，成功后有飞入槽位和五行亮光及原有音效。
- “骑宠”可以更换、转交或取消契约，并切换骑乘/随行；原宠物留在包裹。完整灵宠库、商店、合契入口继续保留。

## 为什么以前看起来丢了宝石

旧镶嵌逻辑成功时从可用堆叠扣一颗，将宝石对象放入装备 sockets 或角色 altar10。旧宝石背包只读取可用堆叠；当前装备界面又没有完整画出孔内宝石。因此这些宝石通常仍在装备中，却在资产窗口中不可见，且缺少稳定身份来反查去向。

本版用旧库存和装备槽位作为唯一持有记录：堆叠以“批次ID＋序号区间”压缩保存每颗身份，镶嵌拆出一个 asset26 ID，拆卸和替换则返还同一ID。9999颗堆叠无需展开9999个对象。“全部资产”只是反查视图，不在可用库存再放一颗副本。

总拥有数＝库存持有数＋已镶嵌数（含装备库、待领取和灵台）。库存内的锁定/收藏仍属于自己，但不能消耗。已经镶嵌的宝石不会进入普通或批量熔炉、重复镶嵌或自动出售材料池。锁定标记独立于位置，拆卸后继续保留；装备中有锁定/收藏宝石时阻止出售或分解。

## 数据安全与旧存档

保留七品质、五次转职、灵宠种类、装备实例、英雄成长、五行与战斗上限。旧存档首次迁入分配身份，不改数量或品质；再次加载不重新生成ID。V25及旧键保留，普通档和独立口令档分别迁入V26键，原文件不删除。

操作经过原有存档校验、修订号/WebLock、防重复收据、保存回读。新的全局校验拒绝重复宝石ID、重叠身份区间、数量不一致或无身份孔位。镶嵌、拆卸、更换装备、交易或保存失败时整体回滚；确认保存后才播成功效果。库存满时不强行取出或丢弃宝石。

## 角色窗口

电脑版采用动态英雄/骑宠预览、装备槽、实战属性三栏。手机版采用横向英雄选择和角色/装备/宝石/骑宠/技能/加点/天赋/转职分类；横屏专门压缩顶部并回收原60像素关闭按钮空白。采用安全区、可滚动内容和44像素分类按钮。

三大属性可展开来源；攻击、法术、护甲、攻速、暴击、冷却、吸血、回复、护盾、五行伤害/抗性均读取现有 stats。装备评分已含其宝石评分，不再把二者相加为重复战力。属性预览只临时计算并恢复原槽位，不保存或消耗资源。

预览复用现有2.5D精灵、骑乘连接、待机和武器灵纹，支持转向/缩放；装备本体使用独立图标。不是新建完整3D骨骼换装引擎，盔甲不会变成全新可替换的3D网格。

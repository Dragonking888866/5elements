# 五行战记 V34：战斗稳定与骑乘修复

修复普通战斗随机全屏抖动、攻击被受击姿态打断、射程边缘反复追击，以及骑乘两腿集中在同侧的问题。保留 V33 的人物和装备原图。

打开 `web/index.html` 可玩；推荐用本地静态服务器或 GitHub Pages。`node build.cjs` 生成正式与隔离沙盒运行文件；`node tests/release-v34.cjs` 执行 447 项检查。需要 Node.js 18 或更高版本。

本地项目保留 `web/` 结构；部署时将其内容放在网站根目录。GitHub 仓库的构建文件和测试使用网站根目录结构。正式存档键未变，继续沿用已有进度。画面设置增加“减少动态效果”，原屏幕震动开关继续有效。

新增源文件为 `motion-fix-v34.js` 与 `rider-anchors-v34.js`；其余改动集中于 `hero-art-v33.js`、`journey-v31.js` 及入口/构建。11 张人物 PNG 的 V33 SHA-256 校验在 `QA-v34-preserved-art.json`。

验收资料在 `验收/`，包含实际游戏截图、原 V33 对照和战斗/骑乘录像；完整说明另见交付的《五行战记-v34-抖动与骑乘修复报告.md》。`tools/` 仅为本地隔离验收工具，不在正式游戏加载。

已验证桌面与手机模拟视口，未验证实体手机；保留原双侧朝向的 2.5D 引擎。当前录屏环境未达到稳定 60 FPS，详见验收报告。

# 五行战记 V20 · 万灵合契

直接玩：https://dragonking888866.github.io/5elements/?v=20.0.0

进入游戏后打开「菜单 → 灵宠合契」。也可以从「灵宠包裹 → 一级合体」进入同一界面。

## 融合规则

品质顺序为：普通 → 精品 → 稀有 → 史诗 → 传说 → 神话 → 极其稀有。

- 两只不同个体、相同品质的灵宠才能融合；一级即可参与。
- 不同品质明确提示「品质不同，无法融合！」，按钮禁用，底层也不会抽取随机数或扣资源。
- 「主宠升品」保留主宠的种族、身份；「异变合体」从已有五行与品质规则对应的物种池抽取结果。两种方式成功都只提升一阶。
- 极其稀有已是最高品质，100%成功口令也不能绕过上限。
- 锁定或收藏的灵宠受保护，需要先解除保护才能参加。
- 正常失败完整保留主宠，只消耗副宠和本次金币；没有新增额外催化材料。
- 无限资源体验沿用原有免消耗规则，结果页据实显示零损失，独立口令档和正常远征仍然分开。

## 新界面与演出

主、副宠卡片直接使用游戏中的动态形象，显示名称、品质、等级、战斗力、主要属性、技能，以及骑乘主人。图像选择器每页18只，支持名称、品质、空陆筛选，适配1000只背包。

成功率使用大字，并按真实概率自动改变颜色：80%以上绿色，50%以上金色，20%以上橙色，更低为红色。手机竖屏顶部另有紧凑概率提示，材料非法时直接显示原因。

完整概率分解显示基础概率、五行关系、全队共享幸运、灵时、失败保护、概率上限修正、五行神石保底和实际启用的体验加成。五行神石是至少70%的保底，并非凭空额外加70个百分点。预览和结算共用真实概率。

本作目前为本地单人游戏，因此显示「全队共享幸运」，没有伪造全服联网加成。

目标预览和结算共用同一个产物构造函数：主宠升品显示确定属性；异变显示可能物种和真实属性范围。成功后保留/获得的技能也会更新。

演出分为灵契蓄力、元素汇聚、灵宠新生、品质展示。传说、神话、极其稀有拥有更长的光柱、符文和星芒演出；失败有灵光暗淡、阵环破碎和主宠归来的反馈。保留原游戏的音效开关，成功/失败有对应短音效。结果页可跳过、确认进背包、继续融合，或返回。

演出只展示已持久保存的结算。关闭、跳过、回看或刷新不会再次扣款。失败回执记录真实损失；存储失败会回滚。最近结果可在刷新后重新回看。

## 手机与性能

- 手机竖屏单列、横屏双列，小横屏回到单列；完整灵宠画布随可用空间缩放。
- 结果页确认按钮和关闭按钮保持至少44 CSS像素高度；适配系统安全区域。
- 修复横屏确认按钮被挤成竖排、遮住灵宠的问题。
- 修复从背包或选择器返回时融合样式丢失的问题，沿用现有单一Esc/返回管理器。
- 融合画布的像素比上限为2，动画桌面最多30fps、手机最多24fps；结果停留后进一步降频，粒子数量有上限。
- 关闭窗口取消动画，旧回调不能重启演出；尊重系统减少动态效果设置。

## 修改文件

- `web/fusion-core-v20.js`：品质拦截、概率分解、结算回执验证、真实属性预览。
- `web/fusion-fx-v20.js`：动态模型、魔法阵、成败演出、动画生命周期。
- `web/fusion-ui-v20.js`：主副宠卡片、选择器、概率与目标预览、结果及回看界面。
- `web/fusion-v20.css`：桌面、手机横竖屏、短屏及减少动态效果样式。
- `web/fusion-v10.js`：抽出共享产物构造函数，回执与资源结算同次保存。
- `web/game.js`、`web/single-player-v16.js`：V20存档键及旧版回退迁移。
- `web/index.html`、`web/sw.js`、`web/manifest.webmanifest`及构建脚本：版本、缓存、模块整合。
- `tests/release-v20.cjs`、`tests/regression-all20.cjs`、`tests/v10-harness.cjs`：核心规则、交易、动画、窗口与旧功能回归。

## 本地运行与测试

需要Node.js，构建：`node build.cjs`；运行检查：`node tests/release-v20.cjs`。

用静态网站服务器提供 `web/` 目录即可玩；例如安装Python后执行 `python -m http.server 8080 --directory web`，打开 `http://localhost:8080/`。

源码包采用 `web/` 目录；GitHub Pages仓库将该目录内容放在根目录，仓库中的构建与测试路径已相应调整。

## 验证范围与边界

226项自动检查覆盖旧版玩法回归、各档融合、五行组合、失败主宠保护、1000只背包分页、概率一致性、回执持久化、存储失败回滚、重复点击、最高品质上限、动画取消和窗口返回。

实际浏览器检查了1440×1000、844×390、390×844及568×320视口，执行了品质不符拦截、真实失败、隔离口令档中的最高品质成功、刷新继续、结果回看、跳过、确认进背包及返回。测试存档只用于本地，没有改变线上玩家存档。

浏览器测试使用视口模拟与点击交互；尚未在实体Android、iPhone及原生Safari上完成性能和触摸手势验收。模型沿用当前游戏的2.5D渲染，本版没有新增真正3D模型或服务端。

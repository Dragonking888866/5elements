# 五行战记 V18 · 星盟新程

直接游玩：https://dragonking888866.github.io/5elements/?v=18.0.0

本次在 V17 游戏工程上修改，保留五名主英雄、地图、灵宠、三石熔炼、五行神炉、装备、转职及单机口令。新增内容已进入实际交易和战斗计算。美术采用已有原创资源和新增原创 SVG，没有引入魔兽争霸的模型、图标或音效。

## 从哪里进入新功能

打开游戏菜单，可找到「五行天赋」「NPC委托 / 救援」「支援名册」「秘器与套装」「批量出售」「药剂包裹」。手机不增加常驻悬浮按钮；头像仍可打开详情，面板内可直接切换英雄。手机右上角固定关闭按钮返回战场。

### 属性与五行天赋

角色属性页每项支持 +1 / +5 / +10 / +100 / MAX，长按连续预分配。一键推荐按职业分配全部剩余点数。右侧或下方即时预览属性，点击「确认加点」后才保存。「取消」只取消本次草稿。营地花费50金币重置已投入的自由属性；成长银行、转职、永久天赋、幸运和旧分配点数不会丢失。

每个英雄有独立六节点天赋树：基础被动、Q、E、高级专精、职业觉醒T、终极R。新专精点预算为 `min(100, 3 + floor((等级−1)/5) + 转职次数×10 + floor(永久攻击成长银行/10))`。已投入的旧永久天赋保留，与新专精分开计算。高级与觉醒节点随着转职开放下一阶，各节点最多5阶。

| 职业 | 真实战斗作用 |
|---|---|
| 金 · 天罡剑宗 | 暴击伤害、穿透招架、突进、剑阵与持续剑雨 |
| 木 · 万木灵医 | 治疗、自然恢复、汲取、持续生命领域 |
| 水 · 寒渊御灵 | 冰封减速、团队回蓝、护盾、寒冰领域；首领控制衰减 |
| 火 · 焚天术士 | 爆炸群伤、持续火域、燃烧与范围提升 |
| 土 · 玄甲守卫 | 生命护甲、团队护盾、真实改变敌人目标的嘲讽与庇护领域 |

五次转职仍保留。转职页现在显示本职业的五阶觉醒，不再给五人显示同一套星陨技能。旧百级职业分支尚未转世的英雄仍可使用初阶职业觉醒。当前已解锁的觉醒阶数仍可选择。三种以上不同元素的存活英雄近距离作战，且队伍投资了高级专精后，提供最多6%的攻击协同；装备攻击光环取附近最高值，最多8%，不按队员数量无限叠加。

### 裂隙救援、支援与NPC委托

旧问题的原因：永恒裂隙首领沿用独立的重复首领奖励路径，击杀时会暂时按非主线首领结算，绕开原来只负责五名主英雄的 `bossReward` 救援逻辑；后续虽记录击杀，却没有裂隙救援事件与角色发放。

现在，权威死亡事件确认「地图6 / 裂隙 / 首领 / 非无奖励对象」后，依次保存通关、创建唯一星璃成员、播放救援，再更新名册。主将倒下不阻断其他存活英雄的救援。重复击杀、离图、重置、读档不会复制成员。旧存档中存在该裂隙首领 `encounters9` 击杀记录时，会自动补发漏掉的救援；仅访问过地图不会补发。

原五位主英雄保持原有单控与编队。额外成员使用**两个支援位置**，不会覆盖原五英雄：跟随主将移动、响应进攻与受击反击命令、独立攻击和周期辅助、获得经验升级，最高300级。附近支援可分担主英雄8%的原始来袭伤害，支援倒下回营恢复。队伍满员时新成员进入永久候补，营地可先撤下一人再换入。支援是可管理的AI队友，不冒充新增可单控的主英雄。

本次六名支援：星璃（裂隙冰棱回蓝）、鹿笙（治疗）、玄铮（岩矢护盾）、烬羽（火矢溅射）、白砚（金剑爆发）、云岚（骑宠主人治疗与灵宠冷却辅助）。长老、教官、导师以及灵宠、宝石、熔炼NPC提供不同委托入口。9项阶段任务各限领一次；巡猎任务每30次新增击杀可领一次金币与灵铁，最多100轮，不依赖现实日期，不重复发放最高级装备或成员。

### 批量交易和药剂

商品、材料、宝石、药剂、灵宠支持 1 / 5 / 10 / 100 / 自定义数量（单次1—100）。按商品实际库存、进度、金币和包裹容量校验；无法足额买入时整笔不结算。长按购买会连续交易，松开、取消、切面板或失焦停止。宝石仍遵守原有每种每日50枚、三级20枚的商店限额；新增玄铁基本材料库存可支持一次100份。任务奖励不使用商店的真实日期规则。

商店支持搜索、品质、价格或等级排序、每页8件、点击图像看详情。横屏手机默认收起搜索和筛选，购买数量仍可直接选择。药剂分红色生命、蓝色法力、金色攻击、银色防御、紫色幸运、五行和高阶复苏共11种原创图像。药剂包裹可点击使用：恢复剂作用于全队存活成员；强化剂作用于当前主将45秒，同类刷新时长；五行强化剂需与主将属性匹配。

批量出售支持普通、一档品质及以下、仅指定品质、等级、评分、重复装备、逐项勾选。确认前显示清单、数量和金币；稀有及以上另需勾选确认。保护已装备、锁定、收藏、绑定、任务、禁止出售、极其稀有及镶嵌宝石的装备，五行神石不会进入此流程。999容量与满额安全自动出售低价值装备继续保留，极其稀有默认保护。交易使用存档版本和唯一收据，防重复点击；存储失败回滚金币、道具与相关运行时治疗。

### 神器词条、套装与冷却

新装备按品质和部位生成固定词条池：技能冷却、终极冷却、技能伤害、汲取、回蓝、暴伤、本系伤害、本系抗性、护盾、附近攻击光环、技能范围、灵宠伤害。稀有有25%几率携带，史诗至少1条，传说2条，神话和极其稀有3条；同件不重复词条。史诗以上的新词条装备附带本系套装标记。3件和6件效果按当前穿戴重算，穿脱不产生永久叠加。

为了避免旧档突然改变战力，旧装备不会自动添加词条；营地「秘器工坊」可花2000金币、10灵铁唤醒一次。结果由装备ID和部位确定，读档不会刷新。所有旧基础威力、镶嵌、附魔和身份保留。

秘器工坊还提供两种同威力、传说品质、双孔、对应主将五行的构筑，每件消耗30000金币、120灵铁、1星核，完成前四章并解封五英雄后开放：

- 天怒：部位威力110，技能伤害 +30%，武器显示金焰锋芒。
- 星轨：部位威力110，终极冷却缩减 +30%，武器显示蓝色星轨。

可选择六个部位打造套装。装备库负责穿戴，工坊展示当前装备词条和实际套装件数。七级以上、稀有以上的宝石有对应五行高级灵效，详情会说明武器100% / 其他装备50% / 灵台65%的计算权重。水系高级宝石提供普通和终极冷却、回蓝；金强化暴伤和元素，木汲取，火技能伤害及范围，土护盾与抗性。

统一公式 `max(技能最短冷却, 基础冷却 × (1 − 合并CDR))`。普通技能CDR与终极合并CDR各受40%上限；Q/E/R/T基础为5.5/11/28/60秒，最短2/4/12/30秒。因此60秒觉醒配10%终极词条实为54秒。正在冷却时换装或拆石按剩余比例调整，例如半程30/60秒换成54秒总冷却后剩27秒；反复穿脱不能刷新。技能伤害乘区只结算一次；汲取沿用有效损血结算，不按过量击杀伤害回血。法力、范围、抗性、盾强和灵宠伤害均有实际计算与上限。

五行神石原有巨额属性、光环、吸血以及高阶宝石/灵宠融合70%保底保留，并增加终极冷却10%、技能伤害8%、灵宠伤害10%；神石重复镶嵌仍去重，且服从统一上限，不改变淬炼或神炉成功率。转职只累计合法永久成长，临时药剂、护盾与自身持续领域会清除，不重复继承装备加成。

## 工程与验证

主要新增文件：`web/rules-v18.js`、`rescue-v18.js`、`combat-v18.js`、`trade-v18.js`、`interface-v18.js`、`journey-v18.css`、`assets/relics-v18.svg`、`tests/release-v18.cjs`、`tests/stability-v18.cjs`。修改 `game.js`、`atelier-v10.js`、`balance-v17.js`、`economy-v17.js`、入口、版本、构建与离线缓存；原模块继续保留。

本地运行（需Node与Python）：

```text
node build.cjs
node tests/release-v18.cjs
node tests/stability-v18.cjs
python -m http.server 8080 --directory web
```

打开 `http://localhost:8080`。部署到GitHub Pages时 web/ 内容放仓库根目录，部署版build.cjs已自动适配根目录结构。正式与沙盒使用同一公共核心、不同独立入口，正常进度和口令分支仍隔离。正常保存键升级到 `wuxing-chronicles-v18`，读取回退到V17及更早存档，旧口令分支可继续。

已验证手机视口、鼠标点击及自动化指针/长按逻辑；本次未接入实体Android/iPhone或原生Safari触摸自动化，不能替代真机测试。游戏继续采用2.5D绘制和本机单人存档，无跨设备账号同步或实时多人服务器。

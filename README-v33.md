# 五行战记 V33 · 英雄重绘

本次保留 Canvas 2.5D 引擎、V31 存档键与全部结算模块，替换 V29–V32 的拼装人体绘制。新增 11 张完整人物姿态图集、350 个人工校准握点，恢复 V31 七档独立武器图。

## 运行与测试

- `node build.cjs`：从 web 内的源模块重新构建正式和沙盒入口。
- `python -m http.server 8080`：浏览器打开 http://localhost:8080/ 。
- `node tests/release-v33.cjs`：410 项历史检查和 21 项新美术渲染检查，合计 431 项。
- `验收截图/index.html`：查看真实运行截图与连续录像；图片、录像均在同目录。
- `tools/browser-qa-v33.js`：隔离 localhost 验收脚本，不能注入正式存档。它在固定姿态验收时持续更新测试演员，避免切到其他窗口造成空录像。自然地图操作模式仍遵守原暂停逻辑。

## 资源与模块

- `hero-art-v33.js`：地图、角色预览、挂点和坐骑共用的人物绘制。
- `hero-atlas-v33.js`：精灵轮廓、姿态索引、350 个握点与武器裁剪框。
- `assets/heroes-*-v33.png`：七品质和四大套装的完整人物；图片无 baked 主武器，实际装备武器独立绘制。
- `assets/hero-grips-v33.json`：人工握点原始坐标。
- `AI-ASSETS-v33.md`：生成资产说明和提示词。
- `history-verified-v33.json`：实际读取的历史提交和原件校验结果。

本地制作工具的原始脚本保留在 tools，路径指向当次工作区，供审阅。生产构建只需 Node，无额外依赖；重新提取图集轮廓需 Python、Pillow、NumPy、SciPy。已生成的元数据可直接使用，无需重跑提取。

## 明确的限制

这是完整姿态精灵与连续网格形变方案，不是 3D 骨骼模型。每套有 2–4 张跑步关键姿态，不能等同于高帧数逐方向动作库；目前左右通过整个人物和武器共同镜像。主护甲决定整套服装，武器、盾牌、首饰和不同品质头盔独立附着；混搭靴子尚无逐款独立外观。弓继续使用原有绘制路径。实际物品数值、镶嵌和所有槽位继续正常计算。

自动回归验证程序正确性，不代表审美验收。真实画面对比、动作录像与手机视口检查应结合查看；没有在实体 Android / iPhone 上实测。

## 已确认的错误与修复

以下结论来自 V21 原代码、可重复的故障注入及隔离浏览器存档，未读取用户报错当时的原始存档，不能把所有历史异常都断言为同一字段损坏。

1. **加点预览持有旧版本号。** 旧面板打开时生成一次请求，之后自动保存、后台保存或其他窗口操作增加版本号，确认便被拒绝。旧按钮还是“预分配”，没有直接提交，容易被误认为失效。现在 +1 / +5 / +10 / +100 / MAX 点击即原子提交，使用点击时版本；推荐加点一次结算。面板内可直接换五名英雄，显示总 STR / INT / AGI、已投入点数、永久与装备来源。
2. **四项功能共用存档锁。** 属性、天赋、宝石和灵宠都经过 `transaction10 / commit17`。另一标签页写入后旧页全部被锁，融合 UI 却统一显示“未结算”，掩盖了冲突。现在区分版本冲突、过期请求、重复请求、条件不符、数据校验、存储权限、空间不足和回读不一致。新按钮加入旧版同一个 Web Lock。菜单增加“存档诊断 / 安全恢复”，显式载入最新存档后即可继续。
3. **写入失败可能仍返回成功。** V21 的底层保存吞掉异常，不返回可判定结果，事务忽略写入结果；部分外层装备提交才补救，基础操作则可能只变内存。现在所有操作统一验证、提交与回读，写入失败还原库存、资源、人物运行状态与口令开关；不覆盖其他标签页较新的存档。界面动画只使用已保存回执。渲染失败不会反过来撤销已经保存的结算。
4. **标题继续使用旧闭包。** 标题打开后另一页更新进度，再点“继续”可能用标题生成时的旧快照覆盖新保存。现改为点击时读取最新正常档；从口令档返回标题时也明确读取正常档。
5. **版本结构与入口兼容。** 新迁移补齐缺省天赋、成长等字段，单独保留天赋已获预算，五次转职不会重复发点或吞掉余额。历史非规范宝石编码保留数量、品质和传承强度；损坏的旧展示回执归档，不据此补发或删除物品。当前 V22 的非法新数据仍被严格拒绝。旧口令档复制到 V22 独立键，旧档与正常档不被口令资源污染。导入上限由 300KB 提至 8MiB，兼容较大的装备与灵宠库存。

## 保存和恢复

- 正常档：`wuxing-chronicles-v22`，可读取 V21 及更早存档。
- 口令档：`wuxing-codes-v22:<世界标识>`，与正常档分开。
- 保存前保留本档上一次有效快照，主键单次写入后回读核验。
- 手动恢复前另留恢复前副本；不会自动清空玩家存档。
- 真正耗尽浏览器空间或被禁止写入时仍会阻止交易，提示具体原因，并允许导出进度；不会以关闭校验的方式绕过错误。
- 此版本没有服务端同步。“共享幸运”是当前单机存档内五名有效英雄的总幸运。

## 宝石、灵宠与装备

保留 V21 七品质和三石配方。三枚合法同品质材料成功升品；正常失败保留第一枚，消耗两枚副石与预览费用。五行神炉、批量熔炼、70% 神石高阶保底和高品质演出继续可用。

两只不同个体、相同品质的灵宠可融合；品质不同禁止，最高品质不能普通升品。成功与正常失败都在事务中记录真实结果；系统异常不作为随机失败处理。失败主宠保留，副宠与费用按原规则消耗。

已回归武器与其他部位镶嵌、拆卸、换装、双孔与五阶灵台、品质淬炼、附魔及重载。镶嵌失败不扣石；拆卸成功精确返还原石，人物生命与法力上限同步收敛。攻速、恢复、冷却、吸血、暴击、五行、护盾和非叠加光环继续使用真实战斗计算与原有统一上限。

## Boss 试炼

在营地打开“菜单 → Boss 难度”选择：

| 档位 | 生命倍率 | 攻击倍率 | 额外首胜奖励倍率 | 大招预警下限 |
|---|---:|---:|---:|---:|
| 普通 | 1 | 1 | 1 | 2.6 秒 |
| 困难 | 1.5 | 1.25 | 1.6 | 2.5 秒 |
| 噩梦 | 2.15 | 1.5 | 2.3 | 2.4 秒 |

以关卡固定基数为主，参战人数倍率最多 3.2，超推荐等级修正最多 1.25。只统计本地图存活且已解封的英雄；装备、宝石、神石战力不用于反向抬高 Boss。

五系各有圈形落点、扇形吐息或冲锋、内圈安全的劫环。血量降低后进入新阶段，出现限量护卫、屏障和短时狂暴；冲锋后和屏障结束后有额外伤害窗口。困难会追加队员落点，护卫上限由 2 增至 4。既有防御、闪避、伤害上限与命中保护保留，没有恢复无预警断命秒杀。

额外首胜奖励包含金币、灵铁和与关卡匹配的宝石；后续征程还有灵焰。原来的装备、灵宠、宝石掉落继续生效。奖励按难度和首领标识去重。未通关地图无人后重置首领并清理护卫；逐关解锁、裂隙救援、大首领三击封印及其他怪物刷新继续保留。

标准化五人普通装备、基础灵宠与推荐等级的输出校准中，主线与归墟样本约 60—96 秒。该脚本用临时无敌隔离输出效率，**不是完整无辅助实机通关测试**；实际时间受人数、操作、词条和五行克制影响。高品质神器理应显著加快击杀，不会被无限自适应抵消。

## 原创支援灵兽

保留六名支援的 ID、招募条件、等级和两席名额，将外观替换成独立小灵兽：

| 旧名 | 新形象 | 主要辅助 |
|---|---|---|
| 白砚 | 金铃剑狐 | 剑气、短时攻击与暴击辅助 |
| 鹿笙 | 青芽灵鹿 | 治疗与绿色灵光 |
| 星璃 | 凝星水灵 | 漂浮、冰晶、恢复法力与减速 |
| 烬羽 | 烬羽幼龙 | 翅膀、摆尾与喷出小火焰 |
| 玄铮 | 玄玉灵龟 | 缩壳与护盾 |
| 云岚 | 月翎灵蛾 | 振翅悬浮、御兽辅助 |

使用原创分部件 Canvas 矢量模型、渐变、眨眼、摆尾、腿步、浮动、施法、受击、出现和召回动画。视觉高度约为英雄的一半，保持原碰撞和寻路尺度；不替换玩家正式战斗灵宠，不占五行英雄名额。名册动画限帧、可取消，并遵循减少动态效果设置。属于现有 2.5D 渲染路径，没有改成完整 3D 引擎。

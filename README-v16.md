# 五行纪 · 口令远征 V16

正式游戏：https://dragonking888866.github.io/5elements/?v=16.0.0

现在可以在正式单人远征中输入口令，直接作用于当前角色、地图、物品和存档，不需要进入体验场，也不需要先输入 `/dev on`。

## 怎么打开

- 电脑：开始或继续远征后，按 **Enter** 或反引号键打开，输入后再按Enter生效并返回游戏，Esc关闭。
- 手机：**菜单 → 第一项「单机口令」**，输入后点「执行口令」。也可用面板快捷按钮和开关。
- 标题页的「查看正式单人游戏口令」只展示帮助，不开始新游戏、不改动已有进度。

## 常用口令

| 输入 | 效果 |
|---|---|
| `greedisgood 1000000` | 金币与灵铁各增加100万；省略数字时各增加500 |
| `whosyourdaddy` | 开启无敌与一击制敌，再输一次关闭 |
| `thereisnospoon` | 开关无限法力 |
| `thedudeabides` | 开关无冷却 |
| `/gold max` | 补满现有金币上限 |
| `/gold add 1000000` | 只增加金币 |
| `/resources max` | 补充金币、材料、药剂、卷轴和宝石样本 |
| `/resources infinite on` / `off` | 免除 / 恢复购买、融合、镶嵌、打造、淬炼、转职的资源消耗 |
| `/pet supreme` | 当前选中英雄获得并装备150级最高品质火龙 |
| `/pet legendary` / `mythic` | 传说 / 神话品质火龙 |
| `/pet supreme ice` | 同样支持fire、lightning、wood、earth、metal |
| `/pet all` | 补齐103种现有灵宠；包裹仍限1000 |
| `/gems all` / `/gem max` | 所有1—11级宝石样本 / 最高级样本 |
| `/materials max` | 补满灵铁、药剂、卷轴 |
| `/equipment all` | 七品质×六部位装备；装备库仍限999 |
| `/level max` | 选中成员达到各自当前等级上限并补充等级自由点 |
| `/rebirth max` | 选中成员五次转职、250级和真实成长字段；重复输入不重复继承 |
| `/skills unlock` | 解锁选中成员的有效技能字段 |
| `/god on` / `off` | 只开关无敌；关闭时也关闭一击制敌 |
| `/mana on` / `off` | 开关无限法力 |
| `/cooldown off` / `on` | 关闭 / 恢复冷却 |
| `/fusion chance 100` / `/fusion reset` | 融合成功率100% / 恢复正常概率 |
| `/pet skill test` | 向当前地图、范围内的合法敌人释放实际灵宠技能 |
| `/pet skill fire_breath` / `flame_storm` / `ultimate` | 火系龙息、火焰风暴、最高品质技能演出；仍需合法敌人 |
| `/dev off` | 一次关闭所有持续开关，已获得的金币和物品保留 |
| `/help` / `/status` | 完整帮助 / 资源和开关状态 |

口令不区分大小写，输入长度最多120字符。未知口令、非法数字和存储失败不会授予资源。无冷却不会跳过正在执行的动作、合法目标和地图规则。

## 进度和备份

第一次在正常存档使用有效口令前，会自动保存该世界的原始进度快照，后续口令不会覆盖这个快照。备份按世界ID保存，包含角色、物品、剧情与位置。

**菜单 → 单机口令 → 恢复口令前进度** 可以查看确认页再恢复。恢复会替换使用口令以后获得的进度，因此需要保留当前进度时，先从系统存档导出。关闭持续开关只恢复正常规则，不会自动收走已获得物品。

口令记录和开关随正式存档保存，正常新游戏会清空开关。V15及此前支持的正常存档自动迁移；原有存档键不会被删除。若导入的是已经使用口令的存档，本机没有原始快照时，不会伪造一份“正常”备份。

独立体验场仍可使用，测试根和测试道具仍不能导入正式进度。正式口令生成的是当前单人游戏中的有效物品，不带体验场标记。游戏没有联机服务器或排行榜；这些口令不是管理员认证系统。

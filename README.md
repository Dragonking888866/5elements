# 五行纪 · 林境焕新 V12

网页版：[打开游戏](https://dragonking888866.github.io/5elements/?v=12.0.0)。本次集中完成开局营地、商会橱窗、灵宠战斗表现三项视觉升级。

## 本次实际改动

- 营地中央的传送门移至北侧林缘，六个目的地与解锁条件保留。已解锁门有流动灵光，未解锁门显示封印石。小地图与实际交互读取同一组坐标。
- 原创树木、林缘、苔岩台地、木栅灯笼、武器架、晶石柜和雕纹石门。建筑、树木、角色、怪物、灵宠、门框共同按脚点排序；角色经过遮挡物后方时降低遮挡层透明度。
- 将直线宽道路改为弯曲土径、碎石和营地石板广场；静态地面一次生成缓存，行走时复用。灯火、水纹和树冠保留轻微动态。
- 百宝商人增加可选商品大图、物品分类、属性说明和直接购买。点击“查看”留在当前商店；交易完成提示不遮挡手机购买按钮。图集按实际物品范围裁切，避免相邻图像露边。
- 灵宠技能的蓄力光、移动弹道、尾迹和命中爆发接入实际伤害事件。火焰有火舌与亮核，冰霜有晶体与冷光，木、金、土使用不同碎片和轨迹；扑击落点有爪痕和地面冲击。
- 命中特效跟随目标实际命中位置。主人倒下、换宠、目标死亡或切换地图时取消尚未命中的相关弹道；特效自身不额外造成伤害。
- 随行灵宠出招时转向目标。保留骑乘关系、飞行振翅、身体起伏、五阶英雄外观、宝石装备特效与全部既有成长规则。
- 修复新增陈列物在未选择角色的标题页读取空角色的问题，并保护无活动存档时的伴宠绘制。

## 在游戏里体验

1. 打开上述网址，旧玩家选择“继续已有远征”。读取 V11 或更早的合法存档，首次保存后使用独立 V12 存档键；原存档键仍保留。
2. 出生点附近点击百宝商人或其帐篷进入商会；选“武器”，点击“查看”看大图，点击金币按钮购买。购买装备进入装备包裹，尚需自行穿戴。
3. 走向营地南侧，可看到宝石柜、铁匠武器架、炼星铺。陈列柜与对应工匠使用相同交互入口。
4. 持有灵宠时，在灵宠面板选择骑乘或随行，前往东侧溪林，点击进攻后用 V / “灵兽技”发动技能。无目标时播放嘶吼，不造成伤害。
5. 北侧灵门按原剧情进度解锁，靠近按 F 穿越；“菜单 → 青禾探索地图”仍可标记路线。

## 交付边界

仍采用 Canvas 2.5D、精灵分层动画与粒子，不是真正全场景 3D 模型。部分远方怪物与已有地图沿用旧素材，本次没有重做全部怪物动画。电脑与手机浏览器可通过同一网址各自游玩，尚无多人实时联网。

安卓 APK 和 iOS 原生工程仍为早期 V5，没有在本次重新构建或上架。iPhone 推荐 Safari 横屏打开，或“分享 → 添加到主屏幕”。390px 布局验收来自桌面浏览器中的手机尺寸页面，不代表真机测试。

详细验证结果见 QA-v12.json；美术工具、保存位置与完整生成提示词见 ART-v12.md。

## 本地运行

需要 Node.js 运行构建与测试；游戏运行时无需第三方库。

```powershell
node build.cjs
node tests/integration.cjs
node tests/stability-v11.cjs
```

通过任意静态 HTTP 服务器提供 web/，打开 index.html。runtime.js 是模块顺序拼接产物，只有一处主循环初始化；改源码后需要重新构建。源码压缩包内包含全部现有贴图，可以单独部署 web/ 文件夹。

## 性能与资源

静态地面缓存为 2400×1600 像素；新增一个约 2.6 MB 的透明场景图集。继续提供流畅、均衡、绚丽三档，粒子有硬上限。实际帧率受设备、窗口尺寸与后台限速影响，未承诺所有设备 60 FPS。

发布时将 web/ 的内容作为网站根目录，使用 GitHub Pages 主分支，原有下载与旧素材保留。Service Worker 已升级缓存版本，正常联网访问会更新资源。

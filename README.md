# 五行战记 V28：装备交互与统一物品属性提示交付说明

直接开始游戏：https://dragonking888866.github.io/5elements/?v=28.0.0

## 1. 装备槽位不能换装的原因

原角色中心的装备入口跳转到整个背包，已有装备的点击路径只展示详情；空槽没有把英雄与槽位传给候选列表。现在角色装备页、槽位选择、属性预览和穿戴确认具有完整的独立路径，点击六个已有槽位均会打开对应英雄、对应部位的候选列表。

## 2. 实际操作与安全换装

操作：角色 → 角色装备 → 点击任意槽位 → 对比 / 选择 → 查看最终属性变化 → 确认穿戴。已穿戴与空槽均可操作；没有合法候选时明确显示“暂无可穿戴装备”。已穿戴物品可查看完整属性与宝石，也可以卸下。

候选支持品质、等级、战力排序，以及名称、品质、五行、基础属性、特殊能力筛选。比较使用真实角色计算函数，包含攻击、防御、生命、三项天赋、攻速、冷却、吸血、宝石和套装阈值变化；同时提示对其他队员的光环影响。临时预览用 try/finally 恢复原引用，不写存档、不耗资源。

穿戴函数验证当前英雄、槽位、物品唯一所有权、等级、明确设置的职业/五行/绑定要求和预览时的原装备。现有普通装备没有新增硬性职业或五行门槛；原本的五行配合规则保留。校验在业务函数中执行，不能通过跳过界面绕过。确认使用原有原子交易与存档机制，写入失败整体回滚。

装备库满999时先移出新装备，再放回旧装备，执行直接交换。卸下时库满则安全进入原有待领取区；待领取区也满时拒绝操作并保留原状。不会为腾位置自动卖掉旧装备。宝石身份和镶嵌关系留在原装备上；未穿戴武器上的宝石仍为“已镶嵌”，不会错误变成可用宝石。锁定、收藏、出售、批量出售和自动装备入口保留；自动装备新增整套变化预览及单次原子提交。

## 3. 装备库与宝石库名称

主界面、折叠菜单、弹窗和库存导航统一使用“装备库”“宝石库”。“角色装备”表示英雄当前穿戴，不与库存混用。宝石库保留全部、可用、已镶嵌、已锁定和特殊宝石视图，并增加五行筛选与排序。已镶嵌宝石显示英雄、装备及孔位；未穿戴或待领取装备也能追踪。

## 4. 全局提示组件

item-model-v28.js 提供 itemInfo28 等统一只读模型；item-inspector-v28.js 以事件委托接管图标提示。装备、灵宠、宝石、支援单位分别通过真实唯一ID解析，刷新时重新读取实际资产。商店商品和配方预览使用有上限的只读展示对象，不能成为第二套物品所有权或存档。

提示展示真实存在的能力，不填虚构零值。装备读取当前词条、强化、附魔、宝石与套装；宝石读取统一品质效果和实际资产状态；灵宠展示实例等级、品质、战力、主人/骑乘、真实技能倍率/范围/冷却与融合条件。现有骑宠没有独立生命条，因此明确展示主人加成，不伪造独立生命、防御。支援单位使用支援战斗计算，明确其支援身份与不可骑乘。

五行神石提示严格对应真实规则：相关高品质融合的成功率最低保障为70%，不是额外增加70个百分点；宝石按目标品质、灵宠按投入品质判定传说及以上，且受当前生效神石与存活英雄条件约束。未把该效果错误应用到淬炼。

## 5. 已接入的界面

通过统一装备样式、宝石图标、灵宠实例画像和支援图标，以及弹窗可见图标适配，接入角色装备/比较、装备库、宝石库、灵宠库、装备坊、宝石阁、灵宠阁、冶金铺、百宝阁、三石熔炉、五行熔炉与灵宠融合。NPC奖励预览使用真实生成规则的展示对象；实际成功领取的Boss、宝箱、任务战利品可在菜单“最近战利品 / 物品属性”查看。已经出售/消耗的资产不会被重新生成为可用物品；交易失败不记录成功奖励。融合结果可查看新实例，旧回放保留当次只读快照，避免宠物升级后篡改历史展示。

这些是代码接入范围，不代表每个面板都完成了独立的人工浏览器遍历；具体测试边界见第7、10项。

## 6. 数据一致性与同步

继续以原存档中的角色装备、装备库、宝石范围/ID与孔位、灵宠和待领取物品为唯一数据源。统一提示不复制可变资产。更换、卸下、镶嵌、骑乘、出售后，根据交易版本和当前英雄重新解析；已删除对象的提示自动失效。对比调用真实属性/上限/队伍光环计算，避免商店、库存和角色中心各维护一份不同数值。

## 7. 测试结果

自动化发布回归247/247通过：14项存档归属与多标签页，22项战斗/资源完整性（含500次击杀），46项宝石资产和角色中心，100项V27套装/Boss/交易，65项本次装备与提示专项。最终展示文字修正后，65项专项再次通过。

新增测试覆盖六槽位、空候选、错误英雄/部位/等级/所有权、999满库交换、待领取溢出拒绝、宝石身份、旧预览提交、多次交换、保存失败回滚、自动换装原子性、旧存档读取、全部灵宠种族的真实技能映射，以及五行神石条件。

实际浏览器已完成武器槽筛选、真实属性对比、确认穿戴、旧武器返回且宝石仍附着、另一英雄不变、鼠标悬停/移开、灵宠商店属性、长按不误购买、关闭提示回到同一选择页等操作。示例换装攻击784→1300，套装6件变5件时明确提示失去相应终极技能加成。

浏览器视口1280×900、390×844、844×390、320×568均检查了提示边界、标题、关闭按钮与横向溢出；结果均未越界。844×390装备列表触摸目标不小于44px。移动交互使用真实DOM与PointerEvent触摸序列模拟，尚未进行实体手机测试。截图来自浏览器视口模拟，部分截图会保留浏览器后备画布的空白区域，以DOM边界检查为准。

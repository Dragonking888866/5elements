# 五行纪 · 五阶星炼 V10.0.0

直接游玩：https://dragonking888866.github.io/5elements/?v=10.0.0

在V9现有游戏上增量升级，保留地图、剧情、五位战士、百级职业分支、灵宠库、五行战斗、三击封印和隐藏征程。电脑、安卓和iPhone浏览器可玩。本次为网页版更新；下载页原有安卓APK和iOS工程仍为V5。

## 从哪里使用新功能

- **宝石 → 宝石熔炼**：双石、异级、三石强化和特殊配方。顶部进入配方图鉴、记录或商店。
- **灵兽 → 一级合体**：同品质主宠升品或异变合体，预览完整属性与实际成功率。
- **装备**：999件共享库存，可锁定、收藏、筛选、排序、查看满库自动出售日志和待领取装备。
- **宝石 → 觉醒灵台**：使用每次进阶新解锁的一个角色公共槽位。
- **菜单 → 五阶转职与觉醒**：查看等级上限、条件、保留属性、觉醒技能与新增槽位。角色属性底部也有入口。

原来的界外征程仍在主界面右侧或菜单中，五位战士全部解封后开启。手机推荐横屏；所有整备面板顶部可直接切换角色。

## 共享幸运与概率

当前是单机多角色模式，“全服”对应本存档五个有效角色，含未出战和未招募角色。测试、删除、无效标记或非法幸运数据不计入；固定五人名单不允许通过添加重复账号扩大幸运池。

`L_total = Σ max(0, 角色幸运)`

`LuckyFactor = 1 + 0.35 × L_total / (L_total + 1000)`

`P_final = clamp(P_base × LuckyFactor + 灵时增益 + 阶段失败保护, 0, 本阶段上限)`

基础概率先受融合方式、五行和等级差调整。界面分别显示基础概率、共享幸运带来的百分点增益、其他增益与最终概率；概率按0–1计算。明确保证成功的低级普通融合除外，高级材料不会因幸运直接达到100%。幸运缓存按状态变更失效，切换发起英雄不会丢失其他角色贡献。

## 灵宠品质进化

保留原品质名称与顺序。仅两只同品质的不同个体可融合，1级开放；最高品质禁止继续普通融合。

| 目标品质 | 配置基础概率（五行调整前） | 最终上限 |
|---|---:|---:|
| 普通 → 精品 | 90% | 99% |
| 精品 → 史诗 | 78% | 96% |
| 史诗 → 稀有 | 65% | 89% |
| 稀有 → 传说 | 50% | 78% |
| 传说 → 神话 | 35% | 62% |
| 神话 → 极其稀有 | 20% | 45% |

五行相生倍率1.08，同气1，相克0.72。每次失败给该品质阶段增加0.8个百分点，最多4.8个百分点，成功后重置。灵时匹配可增加1.5个百分点。

默认“主宠升品”保留主宠物种、主要外观和元素；也保留异变合体及既有隐藏灵契路线。成功消耗双方，等级取较高值，经验取较高值，培养潜力逐项取较高值，不把已经继承过的属性再次相加。新品质倍率实际提高生命、攻击、护甲等收益。高品质分别解锁护主减伤、疾风攻速、灵汲回复；界面显示主副宠属性、技能、战力、目标品质与预计基础成长。

失败完整保留主宠及其骑乘、等级、品质和培养数据，只消耗副宠和金币。融合费用随品质及等级增长，实际费用在确认前列明。包裹仍为1000个独立个体，可按品质、等级、战力排序。

## 十一级宝石、异级补能与特殊配方

原18类宝石ID保留，追加焰锋双曜、森海灵珀、镇岳玄晶、五曜初星、太初觉醒石五类配方宝石，最高11级。普通怪物与商店继续提供基础18类；新增复合与觉醒宝石从配方获得。

| 目标等级 | 配置基础成功率 | 最终概率上限 |
|---|---:|---:|
| 2 | 100% | 同类1级普通融合保证成功；其他组合最多99% |
| 3 | 95% | 99% |
| 4 | 88% | 97% |
| 5 | 76% | 93% |
| 6 | 60% | 85% |
| 7 | 45% | 75% |
| 8 | 32% | 65% |
| 9 | 22% | 50% |
| 10 | 14% | 40% |
| 11 | 8% | 28% |

两枚同级或不同级宝石均可熔炼。默认目标为最高材料等级+1，最高11级；等级差Δ给基础概率乘以`0.65^Δ`。普通组合还受同气1、相生1.04、相克0.72的倍率影响。

材料能量为`E(L)=2^(L−1)`。目标能量不足时，差额每点需要240金币；普通费用另随最高材料等级平方、等级差与方式增加。界面同时显示投入能量、目标能量、补能费用、总费用及产物，避免使用低级廉价材料绕过高阶成本。

三石强化使用三枚同种同级材料，基础成功率乘1.18，仍受阶段上限限制。特定双石或三石组合优先匹配配方，材料顺序不影响识别：

| 配方 | 材料要求 | 结果与条件 |
|---|---|---|
| 焰锋双曜 | 赤焰石＋蓝金石，均≥2级 | 焰锋双曜，攻击与暴击 |
| 森海回响 | 碧生石＋月光石，均≥2级 | 森海灵珀，生命、法力与治疗 |
| 镇岳玄晶 | 田黄石＋玄武玉，均≥3级 | 镇岳玄晶，生命、护甲与减伤 |
| 五曜初星 | 焰锋双曜＋森海灵珀＋镇岳玄晶，均≥6级 | 五曜初星；任一角色完成一阶进阶 |
| 太初觉醒 | 五曜初星＋紫薇＋麒麟珀，均为10级 | 11级太初觉醒石；任一角色完成三阶进阶 |

配方结果等级也是最高材料等级+1。五曜、太初的独立基础概率为18%、8%，仍受幸运、等级差和阶段上限影响。配方图鉴列出材料与条件，炼成后记录发现。失败保留第一枚主宝石，消耗其余一或两枚及金币；每次失败给目标等级阶段增加0.4个百分点，最多2.4个百分点，成功后清零。

宝石攻击、生命等固定属性按独立成长系数提升；攻速、暴击与汲取使用较缓增长及上限。复合宝石提供多五行词条。最终角色暴击、攻速、汲取和减伤另有统一上限，避免多孔无限叠加。

## 装备库存、自动出售与镶嵌

装备库真实容量999件，拾取、首领奖励和打造共用同一入库规则。满库时按品质、基础等级、战力评分和价格比较，优先保留更优物品。自动出售价格沿用`装备强度×3`，收益进入金币余额；现金达到10亿上限时转入金币储备，后续消费可使用储备。

已装备的物品不参与自动出售。锁定、收藏、绑定、任务、禁止出售或镶有宝石的库存装备也不会被自动出售。全部受保护或关闭自动出售时，新物品进入待领取区。手动出售和分解同样检查保护标记；出售镶嵌装备会返还宝石，宝石包裹无法容纳时整笔操作取消。日志保留最近100项重要操作。

装备保留原强度与品质，并区分基础等级、综合等级和穿戴需求：

`综合等级 = min(500, 基础等级 + floor(镶嵌宝石等级之和 × 0.5))`

镶嵌后即时重算装备评分和角色属性，拆卸后恢复。综合等级不会改动穿戴需求。六个装备部位各保留两个镶孔；武器宝石100%能力，其他部位50%。每次进阶新增一个角色公共“觉醒灵台”槽，能力系数65%，五阶最多额外5个；不会给全身每件装备都加一个孔。

镶嵌先选择具体装备或灵台、孔位和宝石，再查看属性、综合等级、评分变化，最后确认。替换和拆卸沿用免费规则，旧石返还。成功有灵光动画与可切换的音效，武器上的高级宝石继续表现刃光，10–11级武器宝石可召唤神兽。

## 五次转职、成长保留与觉醒

本游戏既有最高等级为150，沿用此数值作为初始阶段上限：

| 进阶次数 | 等级上限 | 新增角色公共槽总数 |
|---|---:|---:|
| 0 | 150 | 0 |
| 1 | 170 | 1 |
| 2 | 190 | 2 |
| 3 | 210 | 3 |
| 4 | 230 | 4 |
| 5 | 250 | 5 |

保留百级职业的两条分支，选择后长期继承，不重复计入五次进阶。达到当前阶段上限、五位英雄全部解封、角色存活并返回营地后，支付原有金币和灵铁费用，再二次确认进阶。角色等级回到1、经验清零；已有等级成长、自由加点、职业、解锁技能、幸运、装备、灵宠及世界进度保留。

实现上把完成本世的力量、智力、敏捷等级成长及直接攻击成长存入独立永久账本，装备、灵宠与临时增益单独计算。因此不会把装备加成重复继承，也不会因等级归1清空历史成长。每次再奖励先天幸运3、三项天赋各4、自由点12及一个额外灵台槽。

每次优先补充尚未解锁的五行。角色已有本命元素，前四阶能补齐其余四行，第五阶为五行圆满，仍获得天赋、幸运、槽位和终极觉醒，元素不会重复添加。已解锁元素与装备、宝石及骑宠形成有上限的协同。

五阶各解锁一项可选择的T觉醒技能：护心震（伤害与自护盾）、疾风链（三目标与短时攻速）、镇灵阵（控制）、灵契潮（小队恢复、护盾与灵宠冷却协同）、星陨天劫（三次范围脉冲和金色灵环）。之前的阶段保留，可在转职面板选择；共用冷却以限制叠放。Q/E/R技能随阶段小幅成长，已解锁的R技能在进阶回1级后仍能使用。

## 存档迁移与安全边界

新存档键`wuxing-chronicles-v10`，自动读取V9及更早版本，旧键保留。英雄、宠物ID、装备ID、已镶宝石、地图与奖励记录继续使用。V9历史轮回按最多五阶迁移，已有幸运与天赋全部保留；超过五次的历史收益不会被扣回，但不允许继续进阶。迁移可重复执行，不重复增加金币、天赋或槽位。V9当时已经重置且未记录的历史等级成长无法追溯；从V10起使用永久成长账本完整保存。

融合、转职、镶嵌、出售和打造共用同步事务锁、请求凭据及存档修订号，提交前重新检查所有权、资源和条件。重复提交、过期预览或重复领取被拒绝；异常回滚状态。支持Web Locks的浏览器会串行执行关键界面操作；过期标签页不能覆盖磁盘上的更新存档，需返回标题加载最新进度。

融合使用浏览器`crypto.getRandomValues`判定。当前仍是单机本地存档，没有多人账号或可信服务器；上述机制防误操作、重复结算和标签页覆盖，不代表能防止玩家主动修改本地存档。未来多人版本需要把事务、概率和奖励移到可信后端。

## 修改模块与验证

- `balance-v10.js`：概率、幸运、成本、成长、上限、觉醒和配方配置。
- `state-v10.js`：迁移、校验、幸运缓存、随机源、事务、日志和存档修订保护。
- `growth-v10.js`：统一属性分层、永久成长、五阶突破、五行协同和五个觉醒技能。
- `fusion-v10.js`：灵宠继承、失败保护、双石/异级/三石与配方结算。
- `inventory-v10.js`：999容量、安全溢出、保护、自动出售、储备金币、装备等级评分与槽位操作。
- `panels-v10.js`、`atelier-v10.js`、`systems-v10.css`：融合、库存、镶嵌、进阶和手机适配界面。
- `boot-v10.js`：绑定既有入口，保留原地图、战斗和任务。
- 既有基础模块小幅修改：存档上限、11级宝石校验、进阶后技能保留、灵宠继承元素以及基础掉落池；由23个模块合并为`runtime.js`，只有一个初始化入口。

压缩包中运行`node build.cjs`重建脚本，`node tests/integration.cjs`执行测试。压缩包入口是`web/index.html`，推荐静态HTTP服务器；GitHub Pages仓库把网页文件放在根目录，发布时已适配构建与测试路径。

验证包括96项功能检查，以及固定种子的实际融合结算模拟：灵宠10000次，预览37.80%、实际38.09%；宝石10000次，预览22.00%、实际22.10%。覆盖旧战斗、五行、卷轴、地图、三击封印、隐藏奖励、1000灵宠、999装备、品质进化、异级补能、配方、11级、五次进阶、成长继承、额外槽位、重复请求及过期标签页。模拟期间关闭界面重绘和存储IO，仍使用正式概率与材料结算函数；界面和持久化另有独立测试。

浏览器检查电脑、390像素竖屏及844像素横屏，实际操作了配方熔炼、成功与失败反馈、灵台镶嵌、转职继承和满库自动出售。验收物资与工具仅存在本地预览脚本，未放入正式游戏。

仍需通过长期游玩调整高阶融合金币消耗、五阶角色对逐轮增强首领的通关时长，以及复合宝石与灵宠继承的组合强度；所有本次新增核心规则集中在配置层，便于后续调参。

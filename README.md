# 五行纪 · 掌上远征 V13.0.0

直接游玩：[打开最新版](https://dragonking888866.github.io/5elements/?v=13.0.0)。手机推荐横屏；电脑使用同一个链接。

## 主要变化与操作

- 手机左上信息栏改为 144×44 CSS 像素，默认只显示头像、名称、等级、血蓝条与选中人数；极简模式为 76×44。相较 V12 横屏的 172×93.67，占用矩形面积减少约 61%。详细数值不再长期铺在地图上。
- 点击头像展开角色抽屉，再次点击头像或右上关闭按钮收起。抽屉有属性、装备、灵宠、技能、转职五类；原有面板内切人功能保留。菜单、商店和角色管理只使用一个主弹窗，打开后暂停战场并清空移动输入。
- 「队」按钮展开固定高度的横向头像带，五名成员不会向下撑大 HUD。点头像单选，右下「全选 / 单选」即时切换；阵型和保存编队仍在菜单的「编队」与「更多系统」中。
- 移动摇杆在左下，攻击、Q/E/R、防御、闪避在右下；「全选 / 单选 / 撤退」常驻。药剂、灵兽技、觉醒、宝石神兽、驻守、互动归入「⋯」。装备、合成、镶嵌、商会、任务、地图、转职、存档等归入右上菜单，原完整菜单仍可访问。
- 全选时摇杆移动所有选中队员；单选时只移动当前角色。撤退给选中角色下达离敌移动命令，不传送、不治疗；真正回城仍需消耗原有回城卷轴。
- 摇杆显示圈比响应区小，闲置时淡化；支持固定或动态模式。动态模式在左下空白地图按住出现，并让出人物、店铺、宝箱、传送门、英雄和怪物的点选区域。第二根手指不会抢走摇杆控制权，取消、失焦、旋转和开菜单时会释放移动。
- 菜单 → 界面设置：标准 / 极简、90% / 100% / 112% 大小、45% / 65% / 85% 控制区透明度、摇杆模式及左右 / 向上偏移。偏好独立保存在本浏览器，不写进角色存档。
- 手机镜头依据横竖屏和安全边距调整焦点。刘海边距使用 env(safe-area-inset-*)；Boss 血条避开展开的头像带。探索时技能区降低存在感，战斗时加强，管理面板打开后隐藏无关控件。没有缩放整个网页。
- 桌面分支保留原 HUD、技能栏、鼠标点地、数字切人与键盘操作。V13 存档首次可读取 V12 及更早的合法存档，原存档键保留；换设备请使用菜单导出 / 导入。

## 为什么原界面会遮挡地图

原来的窄屏样式仍沿用桌面状态卡、整排角色与多套功能入口；状态卡固定在左上较低的位置，状态数值和职业文字把高度撑到约 94px。历史样式、按钮栏、回城和营地按钮同时显示。原生 pointerdown 快速代点还会与手机滚动和按钮释放行为冲突。现在用 mobile13 根状态隔离手机样式、统一菜单和角色抽屉，手机按钮采用释放时 click，桌面快速点击逻辑保留。

## 本地运行与复测

需要 Node.js；游戏运行不依赖第三方库。

```powershell
node build.cjs
node tests/integration.cjs
node tests/browser-ui-v13.cjs
```

打开 http://127.0.0.1:8889/qa.html，用 F9 显示 / 隐藏验收工具。工具提供营地、宝箱、战斗、安全边距、布局测量、触摸流程和动态摇杆；只使用 qa-mobile13 存档。普通 index.html 不包含工具和资源种子。若需对照 V12，设置 WUXING_BASELINE 为旧版本 web 目录，在 /baseline/qa.html 打开。

截图复测建议按上述六种真实视口分别截图，先关闭所有面板与工具，再展开头像带和角色抽屉分别检查；逐项点击菜单并关闭，横竖切换后复查按钮。已有自动化为 Node VM 回归，本次增加可复用的浏览器验收页和截图基线，没有引入独立的截图像素差异引擎。

源码包部署时只发布 web/ 的内容；runtime.js 是 build.cjs 拼接产物，主循环初始化必须只有一处。tests/ 与 reports/ 供本地验收，不能插入游戏页面。GitHub 仓库采用网站根目录结构，因此在线 build.cjs / 测试路径与本地 web/ 包装路径略有不同。

## 当前边界与待真机确认

- 本次用了实际浏览器视口和合成触摸事件，未使用真实 Android / iPhone，也未模拟可信多点触控、真实挖孔硬件或 Safari 地址栏收放；这些仍需设备测试。
- 相机受地图边界约束；散开的非当前队员不保证全部同时可见，主动角色优先保持在安全焦点。极小竖屏仍建议横屏操作。
- 没有重新跑 V12 的 600 秒压力战斗；本次完成 138 项回归、实际渲染与交互检查，不承诺所有手机固定帧率。
- 本次交付是新版网页与源码；原生 APK / iOS 工程仍是旧版，不包含这次移动网页优化。存档仍在各自浏览器，分享链接供各自游玩。

# 五行战记 · 五行熔天 V17

直接玩：[打开游戏](https://dragonking888866.github.io/5elements/?v=17.0.0)。电脑与手机共用此链接，手机优先横屏。游戏使用 Canvas 2.5D，网页可分享，每个人的进度保存在自己的浏览器中。

## 从哪里使用新功能

- 菜单 →「三石 / 五行炉」：普通三槽熔炼、批量升级、五行神炉、宝石购买与保护。
- 菜单 →「冶金附魔」：对实际装备附魔、概率淬炼、分解装备；镶嵌界面可选择装备、孔位及具体品质宝石。
- 菜单 →「灵宠合契」：名称、品质、空陆类型、等级和战力筛选；同品质升阶，或选择异变探索新物种。
- 营地的五行宝石阁、五行冶金铺、五行灵宠阁和五行熔炼殿也能进入对应功能。商会内含五行装备坊、五行药坊入口，五行导师归入五行秘术阁。
- 电脑 Enter / 反引号，或手机菜单 →「单机口令」仍可输入口令。首次使用会建立独立口令档；标题页分别提供正常远征与口令档入口。

## 品质、迁移与保护

统一品质为：普通（灰）→ 精品（绿）→ 稀有（蓝）→ 史诗（紫）→ 传说（橙）→ 神话（红）→ 极其稀有（金）。等级与品质是两个独立字段，同等级高品质宝石具有更强能力。

V16 及更早存档自动复制迁移到 V17：旧数字品质2按原名称「史诗」迁移为3，旧品质3「稀有」迁移为2；装备ID、灵宠种族ID、基础威力、培养、技能、剧情和骑乘关系保留。旧宝石从旧规则读取原品质，此后升级不再重新推算品质。原来的 V16 存档键不被改写。换设备前请从系统存档导出 JSON。

宝石堆叠按「类型 / 等级 / 品质」区分。锁定、收藏、绑定、装备中的宝石和神石不会被普通熔炼吞掉。装备中的宝石需要先拆下；替换和拆卸完整返还品质与来源字段。保留原有装备999、灵宠1000、宝石512堆叠容量。

## 三石熔炉与批量规则

普通熔炉必须恰好三枚同品质材料，旧双石入口已停用。

- 同类型、同等级三枚：生成同品质、同类型的高一级宝石，最高11级。基础一级升二级保证成功，其余按配置概率结算。
- 混合等级：产物为最高材料等级+1；等级差降低概率。材料能量按 `3^(等级−1)` 计算，缺口额外支付金币、灵铁，防止一高两低廉价升级。
- 混合类型：命中公开三石配方时产出指定复合宝石，否则保持主石类型；预览不会随机跳变。五行相生提高概率，相克降低概率。
- 失败：第一槽主石保留，两枚副石及费用消耗。缺料、包裹满、非法随机数、重复或过期请求不扣费；保存失败回滚本次交易。

批量支持1、10、100、自定义和「全部 / 自动」（最多10,000次）。可筛选类型、五行、品质、等级范围、目标等级，设置每堆最低保留数量。达到Lv.8以上目标需在游戏内明确确认。每次独立随机、独立收据、独立保存，每片最多处理5次；显示成功、失败、产物和实际消耗。关闭或切换面板会暂停，支持继续已暂停批次；重新载入不会自动扣材料。

公开配方及进阶条件在熔炉详情中可查看：焰锋双曜、森海回响、镇岳玄晶、五曜初星、太初觉醒。原配方发现ID保留。

## 五行神石

五行神石只由独立五槽神炉产出，普通商店、普通宝石授予和怪物掉落池都不会生成。

需要救齐五英雄、实际击败前四章首领，至少一位英雄完成一次进阶。放入最高Lv.11的单元素宝石，金木水火土各一枚。第一次费用为2,000,000金币、500灵铁、20灵焰、2星核；失败后费用逐步提高，每次冷却15秒。灵焰可由怪物掉落或商店购买，星核来自进阶地图首领。

基础成功率5%，受共享幸运有限修正、封顶15%。失败保留五枚宝石，只消耗费用与催化材料；成功消耗材料并产出Lv.11、极其稀有品质的神石。

实际装备神石后：攻击+50,000、生命+350,000、法力+50,000、法术+60,000、护甲+2,500、幸运+1,000，力量/智力/敏捷各+80，暴击和减伤提升，实际伤害汲取10%。周围360范围内存活友军获得非叠加的攻击、法术、护甲、恢复与周期护盾；五色能量环跟随持有者。已有全局暴击、汲取、减伤上限继续有效。重复神石不会叠加本体属性或相同光环。

**当前选中且存活的英雄实际装备神石**，主持目标Lv.8以上的宝石熔炼，或主宠品质为传说以上的灵宠融合时：

`P_final = max(P_normal, 0.70)`

背包里仅持有、其他英雄装备、英雄倒下均不满足条件。神石不作为材料消耗，不影响装备淬炼或神石自身炼制概率。普通概率高于70%时不会被降低。适用阈值、费用和加成集中在 `web/balance-v17.js` 的 `RULES17`。

## 灵宠与冶金

一级即可同品质合契。升品成功保留主宠ID、种族、训练、已学技能、骑乘归属，潜力取合理上限内的较大值；失败主宠完整保留，消耗副宠及费用。异变模式另行改变种族。界面展示主副宠、品质、等级、战力增长和主持英雄的神石效果。

五行附魔消耗匹配元素宝石、金币与灵铁，高阶另需灵焰、星核。金增加攻击，木增加生命和恢复，水增加护甲和法力，火增加法术与暴击，土增加生命与减伤。每元素最多10阶，单件总计20阶，费用按总阶数指数增长；加成进入实际战斗。附魔保留装备、镶孔与原有培养。

品质淬炼逐档成功率为95%、85%、70%、50%、30%、15%。成功升一品质，失败只消耗费用和催化材料，原装备、品质、附魔与镶孔原样保留。神石和「融合100%」口令不会提高淬炼成功率。

三级商品根据五英雄和前四章真实首领战绩解锁，单纯进入高阶地图无效。商店发放的宝石、六部位装备、灵宠都具有实际Lv.3字段；每日库存、价格和重复交易检查生效。

## 美术与手机适配

## 开发与验收

构建：`node build.cjs`。正式验收入口：`node tests/release-v17.cjs` 或 `node tests/integration.cjs`。原V10–V16测试文件保留为历史契约参考，其中双石、旧品质和必成淬炼断言已被V17新测试替代，不应当作为V17规则执行。

本地运行：在 `web` 目录用任意静态HTTP服务启动，例如 `python -m http.server 8893`，再打开 `http://127.0.0.1:8893/`。

## 目前的边界

- 保留Canvas 2.5D与现有图集，新增美术为原创矢量插画与程序特效，未宣称重制为完整3D。
- 共享幸运仍是**当前单机存档中五位有效英雄**共享，包含未出战的有效英雄、排除测试/删除角色。项目没有账号服务器，不能把它当成跨玩家的「全服幸运」或多人联机。
- 无限资源和口令进度写入 `wuxing-codes-v17:<worldId>...`，正常档为 `wuxing-chronicles-v17`。它是单机分档机制，不是服务器防作弊权限系统。
- 浏览器验收使用实际IAB视口和点击/键盘；触摸控制另有自动化指针用例。尚未在实体Android/iPhone、Safari、系统软键盘和刘海硬件上逐台测试。本次交付网页版与源码，没有新的签名APK或iOS安装包。

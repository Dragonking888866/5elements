# 五行战记 V23：星途初醒

直接游玩：https://dragonking888866.github.io/5elements/?v=23.0.0

本版聚焦初始化、技能、救援等级、天赋账本和旧面板状态。保留现有地图、七品质宝石、灵宠融合、装备、支援与口令系统。正常档、口令档、体验沙盒继续隔离。

## 1. 已确认的原因与修复

### 初始化和结算

V22 在完全空白存储下的新游戏，并非每次都会失败。本次没有取得用户当时出错的原始存档，因此不能把所有历史现象归结为一个未经确认的原因。实际复现并修复了以下缺陷：

- 启动链上多个 `begin` 包装器在角色、世界、任务尚未全部初始化时就保存，缺少最终统一发布边界。模拟存储首次写入失败时，旧代码仍关闭标题并进入可操作场景；内存已换成新世界，磁盘仍是旧世界，此后宝箱、加点、融合、交易会一起被事务同步检查拒绝。
- 父面板在交易完成后才被捕获，却使用“捕获时的新存档版本”标记此前绘制的旧 HTML。手机浏览器实际复现：熔炼成功、金币已扣、结果已保存，返回熔炉却仍显示旧材料数量及已禁用的按钮。返回标题会重建面板，所以看起来像重新进入才能使用。
- 关卡 V19 的通关权限和 V9 的隐藏地图存档校验使用不同战绩来源，有真实新版通关记录时，可能允许入图却拒绝保存。

V23 统一通过 `initializeSession23(NEW_GAME / CONTINUE_GAME / LOAD_GAME)`：迁移校验 → 建立角色和世界 → 统一整理 → 最终校验 → 单次主档提交和回读 → ready。中间保存被合并，不关闭校验、不清空存档、不自动刷新或跳标题。失败时保留原档、禁止结算，并提供本页重新初始化入口；不会静默盲重试。继续游戏读取点击时的最新存档；提交前再次检查存储原文，冲突不能覆盖别的标签页进度。

窗口改为记录真正绘制时的 `renderRevision`。交易后返回父面板会从当前 `S` 重新生成界面、数量、预览和事件，不再恢复旧闭包。

### 宝箱与奖励

宝箱金币、宝石和开启 ID 在同一持久事务提交；提交成功后才播放开启反馈。重复点击、切图、读档均检查同一 ID。拒写会完整回滚，宝箱不会假消失。Boss 奖励、救援和通关也合并成同一事务；存储失败会恢复资源、英雄、进度及首领死亡状态。原有任务 claim、首通标记、怪物刷新记录和有界事务收据继续防重。

## 2. 技能成长

| 内容 | 条件 |
| --- | --- |
| 普攻、Q | 初始可用 |
| E | 达到5级 |
| E强化天赋 | 达到15级，并学习Q强化前置 |
| 高级专精天赋 | 达到30级、一次转职、Q强化前置 |
| R终极技能及强化 | R达到50级；强化另外要求天赋前置和点数 |
| T觉醒 | 实际完成第一次转职；按已解锁转职阶段选择 |

规则集中在 `GROWTH_RULES23`，五职业保留原有不同实际技能。前端按钮和 `skill`、`baseSkill`、`ascensionSkill` 都校验。旧的 `skillsKept10=true` 不再直接解锁所有高级技能；正常达到过等级或完成转职的合法技能会保留。已转职英雄等级归1不会丢失先前技能。单机 `/skills unlock` 继续可用，写入独立口令档；T仍需转职。

## 3. 新英雄独立成长

修复了两个层次：旧 `bossReward` 使用队伍平均等级创建英雄；救援后的后续奖励包装器又给刚加入英雄发放本次Boss经验，造成创建为1级后立即升到9级。

现在统一 `createHero23`，每个新五行英雄都有世界范围内稳定ID；首次救援结算完成时严格为1级、0经验、0转职、0自由投入、0天赋点，仅初始Q，不复制其他英雄的成长、装备或技能。新增支援招募也从1级开始。重复救援不会覆盖已有培养。旧英雄不统一降级；只对漏救援的新补入英雄应用新创建规则。

## 4. 天赋账本与平衡

旧预算是 `3 + 等级成长 + 转职次数×10 + 历史攻击成长/10`，历史攻击成长会随转职累积，导致预算过快膨胀。现改为：

- 新英雄初始0点；每达到5的倍数等级获得1点。
- 同英雄、同转职阶段、同等级里程碑只能记一次；每阶段保存已到达的里程碑水位，身份由 `heroId23 + stage + milestone` 唯一确定。
- 每次转职额外1点；第5/9关限定首通各1点，仅发给当时已解封英雄，不向后加入者补发。
- 新成长累计终身上限40点，六节点每节点最高5阶，共可投入30点；高级专精还受转职阶数限制。
- 累计获得 = 已投入 + 可用。重置只清除已投入、返还同一预算，营地费用100金币；同收据不能重复执行。
- 旧档无法可靠追溯的既有天赋和余额作为一次性历史基数保留，最高遵循旧版100点有效数据范围；不随读档反复增加。已有历史基数高于40的不会被强行扣除，也不会继续无限增长。
- 属性点仍每级+3；转职的三项永久根骨各+4与自由属性点+12是不同系统，界面用语已区分，不再误称可消费天赋点。

40点是本版可调平衡参数；后期高装备、极其稀有宝石和多次转职构筑仍需结合实玩反馈调整经验速度及节点收益。

## 7. 本地运行与测试

在工程目录用Python静态服务打开 `web/`，不要直接依赖文件地址的存储行为：

```text
python -m http.server 8080 --directory web
node build.cjs
node tests/release-v23.cjs
```

正式发布用仓库根目录对应 `web/` 内容；工程包保留 `web/` 源结构，网站发布包在 `website/`。旧V22及更早存储键保留，新版自动迁移到V23，不需要清理浏览器数据。

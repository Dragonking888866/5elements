# 五行纪 V6 · 铸星与灵契

公开游戏：https://dragonking888866.github.io/5elements/?v=6.0.1

本次更新网页版。原生Android APK与iOS工程下载仍为V5。

## 界面与操作

只显示战场、简洁小地图、队员头像、生命法力与战斗按钮。点击右上“菜单”进入属性、地图传送、编队、任务、转职、商店与存档设置。装备、灵兽、宝石保留三个快捷按钮。

点击左下头像切换英雄，WASD移动，J普攻，Q/E/R技能，G防御，空格闪避，H药剂，F互动，T觉醒，V灵兽技能。空地框选或Shift多选，右键进攻移动。Ctrl+1/2/3保存编队，1/2/3召回已保存编队。手机使用摇杆、头像与触屏按钮，推荐横屏。

按钮不再随HUD刷新被重建。离散按钮在按下时响应，过滤同次原生点击，避免重复执行。角色切换同时立即更新主将、技能名称和镜头。

## 武器宝石

武器两个孔，当前武器上的宝石增加当前英雄属性。卸下与替换免费，旧宝石返回包裹。武器流转会携带镶嵌宝石；出售带宝石武器时回收宝石。

四种宝石：赤焰石加攻击、沧月石加智力/法力/法术、碧生石加生命/护甲、天运石加幸运。基础值分别为7攻击、4智力、65生命、2幸运；每升一阶翻倍。幸运最高80。

一阶宝石在营地60金币购买。普通妖兽22%掉落一阶，首领必掉二阶。三颗同种同阶宝石，加40×当前阶数²金币，必定合成为一颗高一阶宝石；最高六阶。三至六阶只通过合成获得。

更高阶宝石令武器更亮：从低阶刃光，到三阶粒子、五阶以上电弧与攻击残光。卡片与镶嵌预览同步显示发光。

## 灵兽包裹与技能

包裹最多100只，每次获取均保留独立灵兽，包括重复种类。新获取默认存入包裹，手动分配给英雄骑乘；解除骑乘不会丢失灵兽。每个英雄一只，一只只能属于一个英雄。

骑宠随战斗成长。战斗中会自动进行扑击、喷息或灵能攻击；V或“灵兽技”按钮可主动释放。无目标时可以嘶吼。含抬身、前扑、身体倾斜、骑手锚点同步、声浪与喷息效果。

## 幸运合体

两只不同种类、10级以上灵兽，加250金币，可以预览并确认合体。

成功率 = min(95%, 45% + 当前英雄幸运×0.6% + 双方较低融合星数×2.5%)。

成功后的稀有变异率 = min(50%, 8% + 当前英雄幸运×0.4%)。

成功消耗双方，生成一只随机灵兽，等级取双方平均向下取整，星数最多3。原配方种族具有加权偏好，同时可能出现其他合体种族。另有霜焰龙凰、雷铠玄虎、星冕幻灵、太初龙凰四种稀有变异，使用变色外观与更强基础属性。

失败消耗材料二与250金币；材料一保留，下降1级，经验清零。已被消耗宠物的骑乘绑定自动解除。确认界面明确显示概率与损失。概率为每次独立判定，无保底。

## 验证与部署

在本目录执行 `node tests/integration.cjs`。40项检查覆盖原有地图/战斗/编队/职业、宝石经济与属性流转、随机合体成功和失败、稀有结果、宠物伤害与动画、存档校验，以及连续刷新不替换按钮节点。

`web/`为静态发布根目录；本地使用HTTP静态服务器打开。代码由game.js、upgrade.js、expedition.js、conquest.js、sanctuary.js依次合并为runtime.js，只有sanctuary.js末尾启动游戏。

新存档键为wuxing-chronicles-v6，保留V5/V4等旧键并自动读取迁移。首次迁移赠送一枚赤焰石和一枚天运石。测试演示页与种子数据只在本地验收服务器，不包含在发布包中。

游戏为原创二维单人RPG，不含实时多人联机。玩家各自使用本地浏览器存档。

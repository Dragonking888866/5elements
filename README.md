# 五行纪 · 青禾新程 V11.0.0

直接游玩：https://dragonking888866.github.io/5elements/?v=11.0.0

本次在V10工程上增量升级，使用原来的JavaScript / Canvas自定义引擎，保留五行、主线、十一张地图、角色编队、五阶成长、装备、11级宝石、灵宠与旧存档。没有替换引擎。本版是可玩的2.5D网页版，未生成新的安卓APK或iOS安装包。

## 从哪里开始

1. 用原来的浏览器打开上述网址，点击“继续已有远征”。新玩家选择角色后点击“踏上远征”。
2. 营地核心是安全区。点击实际人物或店铺进入功能，远处点击人物会先寻路，走近后自动交互；也可以靠近按F或点屏幕上的附近交互按钮。
3. 向东沿古道进入流萤溪林，先打低级怪，打开附近补给箱。打开“菜单 → 青禾探索地图”可标记路线。
4. 找到巡林教官红绫，接受委托。击败4只营地外围妖兽、打开1个新宝箱后可领取180金币、二级鸡血石与精品银鬃战狼；只能领取一次。满灵宠库或对应宝石满堆时保留领奖资格。
5. “灵兽”面板顶部新增“骑乘 / 随行伙伴”。随行灵宠独立寻路，攻击从它所在的位置发出；切换不改契约、属性和装备。
6. “菜单 → 画面 / 帧率”选择绚丽、均衡、流畅。电脑可用绚丽；低性能设备可选流畅。手机推荐横屏。

存档仍在本机浏览器。V11使用独立存档键，首次会读取并迁移V10及更早存档；原V10键保留。换设备请先从游戏菜单导出存档。分享链接供其他人各自游玩，目前仍不是实时多人服务器。

## 灵宠动作与战斗

宠物攻击新增游戏时间驱动的命中队列：

- 扑击：前摇0.22秒，短距离接近/撕咬，接触阶段命中。
- 飞行俯冲：前摇0.32秒，抬升、俯冲、命中与回落。
- 吐息/魔法：前摇0.30秒，按距离飞行的弹道，抵达时结算。
- 后摇通常0.35秒，冷却仍依照原手动8秒、自动11秒规则。

地面扑击限制在160范围、俯冲300范围，吐息和魔法可远程释放。伤害结算经过原五行、装备、宝石与品质系统，不在攻击刚开始时预先扣血。命中闪光、五行粒子、伤害数字和轻微镜头反馈同步触发。主人倒下、换宠或换图会取消尚未命中的事件，不能跨图杀怪。

飞行宠物保留羽翼振动、高度与投影，地面宠物保留四足、跳跃、爬行等步态。新动作把身体重心、俯仰、前冲和鞍位联动；骑手随鞍位移动。随行宠物有独立位置和路径，不再始终与主人重叠，仍受主人活动范围约束。主人受击时宠物有同步反馈；主人倒下时随行宠物收束淡出，宠物当前没有独立生命条。

合体成功和失败均使用真实事务结果触发演出，展示双宠能量汇聚、法阵和最终结果；成功品质决定光色，失败清楚保留主宠。支持系统“减少动态效果”偏好。

## 渲染与性能方案

保留Canvas 2.5D引擎：统一脚点深度排序、图集裁切、树木/建筑遮挡淡化、接地投影、环境光、水面波纹、火焰与烟雾、粒子与稀有光柱。摄像机保留原平滑跟随。没有用CSS透视冒充真正3D。

三档画质：绚丽最多180粒子/8组光效，均衡90粒子/4组光效，流畅36粒子/1组光效并以30FPS呈现。渲染分辨率分别为逻辑尺寸的100%、90%、72%；坐标输入、寻路和战斗始终使用同一逻辑尺寸。粒子对象回收池、视野裁剪、特效数量上限、同帧属性缓存减少负载。属性缓存仅在单次更新/渲染内使用，等级、宠物成长、加速到期、灵时和事务变化会失效，面板预览直接重新计算。

真实浏览器实测：桌面嵌入式浏览器，60只存活怪物的压力场景，最终流畅档约30FPS，最近240个渲染样本平均约6.82ms；逻辑画布1280×720，流畅档物理画布约922×518。此前均衡压力样本为24–28FPS，环境分辨率发生过改变，不能作为严格前后对照。高档60FPS是目标，当前没有验证达到；页面后台限速也会影响结果。

手机在浏览器内以390×680竖屏布局检查并实际购买；这不是安卓或iPhone实体设备性能测试。菜单、面板可滚动、商品双列、触控按钮可用。原横屏触控布局保留。

## 已知限制与后续素材

- 仍是2.5D，不含真实3D网格、骨骼绑定、PBR材质、三维地形和动态体积光。角色死亡等动作仍使用原帧与分层过渡，不等同于专门制作的全套多方向动画。
- 百种灵宠继续复用现有图集和若干动作族；本次没有为每种灵宠新绘完整八状态、多方向动画。待补充逐物种的骨骼/多帧资源及口部、爪部锚点精修。
- 普通攻击和部分旧英雄法术保留原结算方式；本次完整的延迟命中改造集中在灵宠。旧地图怪物保留既有AI；新的障碍绕行实现重点覆盖营地新增怪物。
- 高画质稳定60FPS、安卓/iOS真机GPU与耗电、数小时实体设备测试尚未完成。手机弱设备建议流畅档；这版没有宣称达到魔兽或Dota商业游戏的模型与动画精度。
- 仍为本地单机存档，无实时多人服务端、防改档服务器或云账号同步；原V5移动安装包没有同步升级。

新增素材采用内置图像生成工具制作，未复制魔兽或Dota的版权模型、贴图与音效。素材文件、精确提示词和来源说明见`ART-v11.md`。

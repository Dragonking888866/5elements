# 五行纪 · 诸界远征 V5.0.1

原创 2D 五行冒险 RPG。人物采用新的手绘动作帧，装备以六部位卡片展示；默认关闭战场零碎装备覆盖，实际属性始终生效。

## 本版内容

- 单独控制五位英雄、Shift 点击追加选择、拖动框选、三组可保存编队、横队/楔形/环形阵型，支持驻守、跟随和进攻移动。驻守成员不会被传送到主将身边，位置与命令随存档保留。
- 7 张独立地图，每张 4800 × 3200：诸界营地、翠影迷林、熔火裂谷、霜镜群岛、沉岳古城、无相王庭、永恒裂隙。地图有河谷、桥梁、遗迹与城墙碰撞，地面移动命令会寻路绕行。
- 世界面板和场景传送门切换地图。五张元素地图随主线开放；任意英雄30级或主线通关后解锁裂隙。每张副本入口可重置怪物，主线奖励不会重复领取。
- 每名英雄100级可选择两种职业之一，共10种分支；保留等级，提升上限至150，并增加属性、职业加成及觉醒技 T。
- 12 种普通宠物，加3类拥有独立美术的合体灵兽。两只不同的10级以上宠物与250金币可合体，确认后消耗材料，结果保留平均等级，最高3星。青龙+朱雀为龙凰，白虎+玄武为玄虎，其余组合为星灵。
- 五行技能增加多层法阵、光轨、碎片、火羽、冰晶和大招辉光；支持切换绚丽/流畅特效档位。

## 操作

电脑：WASD/方向键仅控制当前主将；点击角色或头像单控，Shift 点击角色多选；在空地拖动框选；点击地面让选中成员移动，右键地面进攻移动。Ctrl+1/2/3 保存编队，1/2/3 优先召回已保存编队，没有保存时仍选对应角色。4/5 选择对应角色。

J 普攻，Q/E/R 当前主将技能，G 防御，空格闪避，T 转职觉醒技，H 恢复药剂，F 传送门/宝箱/场景任务，B 装备。

手机请横屏。左侧摇杆单控当前英雄，顶部「编队」可全选、驻守或跟随，再点地面下达移动。转职与觉醒技可在暂停菜单操作。

## 运行和工程

`web/index.html` 为网页入口，无第三方前端依赖。用静态服务器托管 web 目录即可运行。公开发布包还包含安装包与工程下载文件，可完整上传网站。

`android/` 为 Android 8+ 的离线容器，`build_apk.py` 为重建脚本。此交付 APK 使用开发测试证书，不是应用市场正式发行签名。

`ios/Wuxing.xcodeproj` 为 iOS 15+ 的离线工程，需 Mac/Xcode、自己的 Team 和唯一 Bundle ID。没有提供 IPA。收费上架仍需开发者账号、签名、真机测试、资料与协议及 Apple 审核；见 iOS 目录说明。

在此源码目录运行 `node tests/integration.cjs`，检查游戏逻辑。`tests/check_package.py` 检查项目资源与 APK 文件一致性。

## 存档与发布

V5 使用独立存档键，首次可读取 V4/V3/V2 进度；旧角色等级、装备、骑宠、主线和场景任务保留，旧世界位置迁回新营地。旧版存档不会主动删除。跨设备请导出/导入 JSON。

正式网页：https://dragonking888866.github.io/5elements/?v=5.0.1

当前是单人游戏与可控制的小队，分享链接后朋友各自游玩，没有实时多人世界。没有账号、广告 SDK 或云存档。

视觉仍为2D手绘动作帧与程序特效，战斗与成长数值为原创设计；未使用魔兽、暗黑或 Dota 的素材。测试演示场使用预设的100级数据验收功能，不会作为正常开局发布。安卓和 iOS 的实际设备兼容性与长时间性能还需真机测试。

# 五行纪 · 轮回诸界 V9.0.0

直接游玩：https://dragonking888866.github.io/5elements/?v=9.0.0

电脑、安卓与 iPhone 浏览器均可打开，手机推荐横屏。这次更新的是网页版；下载页原有安卓安装包及 iOS 工程仍为 V5。分享链接后每人使用自己的浏览器存档，当前没有实时网络联机。

## 新征程与致命首领

五位战士全部解封后，主界面出现「界外征程」。归墟浮陆建议110级，破关后进入九幽炼狱（130级），再进入太初神庭（150级）。每张地图有独立障碍、通路、界门、小首领与界主，敌人比旧地图更强。

新界主会循环释放三种致命技能：断命陨星固定瞄准释放前的位置；裁决裂光朝固定方向劈出；归零劫环的内圈和外圈之外安全。预警持续约2.3–2.9秒，走位、绕后、进入安全区域或闪避可避开；被命中会倒下，普通防御、护甲和护盾无法抵挡。

三座新地图各藏一枚印记。先击败当地第一位小首领，再靠近发光印记按F；征程手札可以追踪。集齐三印并击败五劫神皇后，太初神庭南侧开启时隙秘境，建议165级，需用转世、装备与灵契弥补英雄本世150级的上限。秘境藏有隐藏首领和灵契线索。隐藏伙伴不会直接出现在商店或未发现的图鉴中，满包裹时奖励暂存，可腾出位置后在征程手札领取。

## 首领封印与逐轮增强

| 等级 | 基础刷新间隔 | V9刷新规则 |
|---|---:|---|
| 普通怪 | 35秒 | 持续刷新，逐轮增强 |
| 小首领 | 120秒 | 持续刷新，逐轮增强 |
| 大首领 | 360秒 | 同一出生点累计击败3次后永久封印 |
| 终极首领 | 720秒 | 持续刷新，逐轮增强 |

普通、小首领、终极首领每轮增加生命、攻击和等级。记录跨切图、读档和转世保留；大首领第三次被击败后留下封印。菜单暂停刷新计时；玩家靠近出生点240范围时延后刷新。重置地图无法跳过冷却或清空封印。菜单的首领记录可查看次数与轮次。

V8没有历史重复击杀次数。迁移时，已确认击败的前四章主线大首领各计1次；无法追溯旧版本其他重复击杀，从V9开始精确累计。

## 可反复转世

「菜单 → 轮回星坛」或角色属性底部进入。五位战士全部解封、当前英雄达到150级、存活并返回青禾营地后，可以支付金币和灵铁转世。

- 每次永久增加先天幸运3点，力量、智力、敏捷天赋各4点，脱下装备后仍然保留。
- 本角色回到1级，经验、职业、本世自由加点重置，获得12点自由属性；100级可重新转职，150级可再次转世。
- 装备、镶嵌、灵宠、其他英雄、地图进度与首领封印保留。
- 首次费用20,000金币＋80灵铁，以后每次增加15,000金币＋40灵铁，费用分别封顶5亿金币与5千万灵铁。
- 先天幸运独立于装备幸运上限，继续影响灵宠和宝石合成；最终成功率仍有上下限。

## 灵宠1000只与同品质进阶

包裹最多容纳1000个独立个体，保留100种常规灵宠并新增3种可探索的隐藏灵契。包裹可按品质或等级降序排列，仍有分页、五行与品质筛选。

一级即可合体，但材料必须是两只同品质的不同个体，可以同种。成功品质必升一档；最高「极其稀有」后只提升等级，灵宠等级上限150。

- 「主宠升品」保留材料一的物种与等级，适合长期培养喜欢的宠物。
- 「随机合体」可能诞生新物种，普通成功时等级取双方平均值向下取整；特定条件可产生隐藏灵契。
- 失败完整保留材料一，消耗材料二和金币。使用正在骑乘的材料会解除其骑乘绑定。
- 五行相生更容易，相克更难；当前英雄幸运和干支灵时会影响预览中显示的实际概率。费用随品质和等级增加。

## 六部位可视化镶嵌台

点击主界面的「宝石」，或「装备 → 进入六部位镶嵌台」。顶部可以直接换英雄；左侧选头盔、首饰、护甲、武器、防具、靴子，中间选两个镶孔之一，宝石包裹选具体宝石，点「预览镶嵌 → 确认镶嵌」。

每件装备有两个镶孔。武器获得宝石100%能力，其他部位获得50%；战场中的武器光芒随武器宝石变化，其他部位只体现属性。替换或取下免费，旧宝石返还；包裹堆叠满时不会丢材料。成功时有灵光流入、镶孔闪烁和提示，开启「音效」后有镶嵌和弦。

宝石分1–10级，品质由等级决定；合成只接受两枚同级、同品质材料。可以使用不同名称的同级宝石，五行关系与幸运决定异种合成成功率；失败保留材料一。高阶材料继续按两枚升一级，10级封顶，可在武器上激活天极神兽召唤。装备按品质或装等排序，宝石按品质或等级排序。

## 常用操作与存档

点击头像单控，Shift追加选择，Ctrl＋1/2/3保存编队。WASD／触屏摇杆移动，J或「进攻」开始主动攻击；普通移动、驻守与默认状态只被动迎击。Q/E/R技能，G防御，空格闪避，H药剂，F互动，V灵宠技，T百级觉醒，Y天极神兽。

回城消耗1张卷轴；营地可购买卷轴、宝石、灵宠，分解装备获得灵铁，打造与淬炼装备。五行相生相克继续作用于英雄、怪物、灵宠、装备与宝石。画面为图集、分层动作和粒子结合的2.5D表现。

新存档键为 `wuxing-chronicles-v9`，自动读取V8及更早版本。原存档键保留，旧宠物ID、装备和物品不变。建议先在菜单导出存档；换手机或浏览器时可导入。首次完整加载后缓存游戏资源，收到更新后刷新页面即可。

## 工程与验证

`web/index.html`为入口，推荐静态HTTP服务器运行。修改源码后运行 `node build.cjs` 合并15个模块为 `runtime.js`；运行 `node tests/integration.cjs` 执行78项检查，覆盖战斗、五行、存档、转世、三次封印、逐轮增强、1000容量、品质进阶、镶嵌、隐藏征程和持续战斗帧首领栏。

浏览器验收使用独立本地测试进度，检查电脑、手机横竖屏面板和实际素材加载；测试物资与快捷工具未包含在正式游戏中。网页使用静态资源，无运行时第三方CDN、账号注册或游戏内付费。

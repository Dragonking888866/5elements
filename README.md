# 五行纪 · 灵脉复苏 V14.0.0

直接游玩：[打开 V14](https://dragonking888866.github.io/5elements/?v=14.0.0)。请在保存过进度的同一浏览器点击「继续已有远征」，不要清除浏览器数据。

## 这次解决什么

### 后期 Boss 不再频繁直接秒杀

旧界外首领的所有预警招式都会绕过护甲与护盾清空生命，第三阶段释放间隔只有4.5秒。V14将其替换为正常伤害结算的重击：

- 界外普通重击预警3.2秒，释放后冷却10–12秒；位置在预警开始时锁定，离开范围即可完全躲过。旧主线首领的技能预警至少2.4秒，释放后冷却至少9秒。
- 终极重击只在终极首领或隐藏首领的最终阶段、每四轮技能时出现，且与上一次至少间隔45秒；预警4.4秒，释放后冷却14秒。
- 首领普攻单次伤害最多约角色最大生命24%，重击42%，终极重击65%；这是最不利五行关系下的上界，护甲、防御、护盾和角色减伤仍会继续生效。满血不会被单次技能直接清空，残血仍可能倒下。
- 重击命中后有0.9秒短暂保护，减少首领与杂兵连续补刀；阶段切换保留至少6秒技能缓冲，普攻出手间隔不低于1.8秒。
- 屏幕上方单独显示技能名、剩余预警时间及「离开红圈 / 绕到侧后 / 内圈安全」；首领出现时隐藏与其重叠的普通提示。

### 有稳定刷金币和基础材料的地方

打开「菜单 → 任务或传送 → 金币与材料」，进入青禾资源谷。营地南侧也增加了资源谷灵门。1级可进入，没有首领；24只普通资源妖兽分布在三个采猎区：

| 采猎区 | 每只保底金币 | 每只保底灵铁 | 基础宝石 |
|---|---:|---:|---|
| 金砂旧矿 | 42 | 1 | 无 |
| 灵铁采场 | 30 | 3 | 无 |
| 碎晶花园 | 32 | 1 | 1枚一级基础宝石 |

资源怪20秒刷新，站在其出生点120世界单位内时延后刷新；离开后会刷新。强度固定，不随击杀轮次或角色等级增加。没有挂机金币结算，必须击败资源怪。这里的击杀不计算主线解除屏障的进度，也不会重复发放守护者或章节奖励。资源谷保留独立刷新记录，读档和切图不能提前刷新。回营仍需要1张回城卷轴，入口的商会可以补给。

### 手机五章主线可直接查看，火土英雄能救出来

「任务」和「传送」现在都打开灵脉旅图，顶部「主线 · 五章」始终显示一、二、三、四、五五个按钮。未开启的章节也能查看锁定原因，选择章节不会立即传送，点击「进入第X章」才传送。

以金行凌锋开局时：第三章霜镜群岛通关后赤霄（火）入队；第四章沉岳古城通关后岳岩（土）入队，接着可进入第五章无相王庭。五人齐聚后归墟浮陆也会开放。选择其他初始英雄时，守护者依次解救尚未加入的伙伴，避免重复招募。

读取旧存档时，按已完成的守护者记录同步章节和应有伙伴数量。已通关但漏招募的伙伴会补回，保留金币、装备、宝石、灵宠和原角色培养，不重复发放通关物品；没有通关记录时不会凭等级直接开放章节。

### 手机横屏视野与清晰度

横屏从「大人物挤满画面」改为更宽的地图视野；844×390视口下，世界视野由约971×449扩大为1367×632。中档画布为1266×585，使用高质量图像平滑；高档可提高采样，低档保留流畅选项，画布总像素有上限。没有缩放整个网页。

左上紧凑信息栏、可折叠队伍、全选、单选、摇杆、攻击和撤退保持可用。568×320小横屏的章节进入按钮移到右侧可见区；避免章节存在但进入按钮沉在屏幕外。桌面保持原分辨率和键盘操作公式。

## 改动文件

主要实现在 `web/renewal-v14.js` 和 `web/renewal-v14.css`，包括章节导航、旧进度同步、资源地图、独立掉落与刷新、首领重击节奏及横屏渲染。另修改：

- `web/ascension-v9.js`：原四张界外地图的生成范围固定为ID7–10，避免新资源地图读取不存在的古神配置。
- `web/atelier-v9.js`、`web/menagerie-v8.js`：资源谷可在五人未齐时合法保存，允许ID11的刷新记录；原界外解锁验证保留。
- `web/upgrade.js`：闪避的封印区域只判断当前地图，第三章不再被第四章相同坐标错误打断。
- `web/journey-ui-v9.js`：玩法说明与重击规则一致。
- `web/game.js`：V14独立存档键，可读取V13、V12及更早合法存档，旧键保留。
- `build.cjs`、`web/runtime.js`、`web/index.html`、`web/sw.js`、`web/downloads.html`：模块、样式、V14缓存与在线版本入口。
- `tests/renewal-v14.cjs`：15项本次回归；旧用例只调整地图新增数量和已经被取消的强制秒杀预期。
- `tests/browser-ui-v14.cjs`：隔离本地存档的浏览器验收入口，新增火土通关、资源掉落和终局预警测试场景。不会注入正式游戏。

## 验证结果

完整自动化 **153/153通过**，包含原有138项（有意更新的旧规则断言）与本次15项。对五种初始英雄分别模拟真实主线击杀、守护者奖励和解锁流程，都能救齐五人并进入归墟。验证了旧存档漏招募修复、资源三类保底掉落、重复击杀保护、多轮恒定强度、20秒刷新与读档、回城卷轴、首领伤害边界、护盾格挡、闪避保护、终极技能频率及地图渲染。

实际浏览器检查：

- 通过正式菜单进入第三章；本地测试场景触发真实守护者伤害与奖励管线，界面显示赤霄入队，随后第四章显示岳岩入队；最终5/5，章节4（第五章），存档验证通过。

- 六种实际视口844×390、667×375、568×320、390×844、360×640、320×568的常驻按钮均至少44px，无按钮重叠、裁切或页面横向溢出，中心点击命中正确。

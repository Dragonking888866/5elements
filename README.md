# 五行纪 · 行者之约 V4

原创五行冒险 RPG。五名战士、十五个技能、五种骑宠、六部位装备、五章首领与电脑队友。

- [打开游戏](https://dragonking888866.github.io/5elements/)
- [安卓下载 / iOS 工程 / 安装说明](https://dragonking888866.github.io/5elements/downloads.html)
- [隐私说明](https://dragonking888866.github.io/5elements/privacy.html)

网页文件位于仓库根目录，无需构建。Settings → Pages → Deploy from a branch → main → /(root) → Save。实际发布状态以 Pages 为准。

WASD/方向键移动，J 普攻，Q/E/R 技能，G 防御，空格闪避，F 互动，1–5 切换成员。手机横屏使用摇杆和技能按钮。演武场可预览跑步、攻击、防御、施法、骑乘动作；旅途面板追踪场景支线。

当前是单人冒险，伙伴由电脑操控。分享链接后朋友各自游玩，不支持实时多人联机。进度保存在本机，可导出导入 JSON。

安卓 APK 已构建并校验 v2/v3 测试签名，支持 Android 8+，没有真机验收。iOS 下载项是完整离线 Xcode 工程，最低 iOS 15，尚未在 Mac 上编译、签名或提交 App Store；不能直接当 IPA 安装。未来付费上架需开发者账号、真机测试、协议税务与审核。

本次美术为原创生成素材和程序绘制，未打包魔兽、仙剑的角色或场景资源。19 项游戏逻辑集成检查通过；桌面浏览器画面和交互已检查。商业发布前仍需发行方完成权利、设备和发行要求复核。

直接游玩：https://dragonking888866.github.io/5elements/?v=27.0.0

电脑与手机浏览器使用同一网址。本版更新网页游戏，保留五行英雄、七级品质、灵宠、宝石唯一身份、装备镶嵌、五次转职及已有征程。

## 先从哪里体验

菜单 → 四象套装图鉴：随时查看收集进度、六个部位、套装能力与材料。

菜单 → 店铺导览 / 寻路：标记并步行至对应 NPC，到达合法范围自动打开。只有本店业务可实际结算。菜单 → 百宝包裹：对指定英雄或指定灵宠使用已持有的经验书、药剂和道具。

手机右上角 × 直接关闭全部面板返回地图；Esc 保留返回上层窗口。横屏压缩重复标题和返回按钮，保留 44 像素触摸按钮与安全区。

## 1. 四套装备为什么以前难以得到

原代码 `rollAffixes18` 会给史诗以上装备附带 `set18=五行`，并不是完全没有套装。问题是同时依赖随机品质、随机五行、随机部位，缺少指定部件掉落表、套装材料、委托与定向锻造。原火套界面还混用了“焚天”名称；现在统一显示“梵天”，保留原来的 set18=3，不更改旧装备身份。

现在每套仍为武器、护甲、首饰、头盔、防具、靴子六件，有独立图标及 2 / 4 / 6 件效果：

| 套装 | 主要首领来源 | 两件 | 四件 | 六件 |
|---|---|---|---|---|
| 长生 | 第6关 星渊·无相渊魔 | 生命+10%，每秒恢复+0.2% | 汲取+3%，治疗+8% | 每8秒治疗附近友军1%生命 |
| 玄潮 | 第7关 归墟龙王 | 法力+12%，每秒回蓝+0.2% | 技能冷却-8%，控制+15% | 终极额外冷却-8%，控制+10% |
| 梵天 | 第8关 九幽魔尊 | 攻击+10%，本系伤害+8% | 暴击+6%，技能伤害+12% | 终极伤害+30%，烈焰星环 |
| 镇岳 | 第9关 太初神皇、第10关 逆命星君 | 生命与护甲+12% | 护盾+25%，减伤+3% | 附近友军护甲+10%，同类不叠加 |

原天罡套装保持。新四套在实际 `stats` 中计算，移除旧 3/6 件重复计算；恢复光环按战斗时间触发，技能伤害、吸血、控制、护盾与护甲沿用原战斗结算。

高级首领掉落部件概率：普通6%、困难8%、噩梦12%，随机六个部位之一。普通/困难产出传说，噩梦产出神话。每次同时必掉对应套装碎片3/6/9，首领之魂1/1/2。普通怪不直接产出完整顶级套装；高级精英有15%机会掉一枚对应碎片。

高级地图稀有宝箱必得2枚对应碎片，另有3%部件机会。营地长老有四项一次性首领悬赏，各奖励12枚对应碎片与1首领之魂。冶金铺可选套装与任一部位，花费50,000金币、600灵铁、8灵焰、1首领之魂、12对应碎片，必定打造一件传说部件；须先合法解锁对应地图。

套装不会自动卖掉。满库时进入待领取区；极端暂存上限时，首领部件随机奖励折为12枚对应碎片，并提示。重复部件可按保护规则手动出售或分解，镶嵌原ID宝石返回。

## 3. 首领战斗与原创美术

在V22关卡基数、人数、等级、波次与难度计算后：第1—3关生命×2，第4—5关×2.5，第6—8关×3，第9—10关×2；攻击在前五关×1.3，后续×1.45，防御基数×1.5。只在一次配置时放大，切难度或重进不会重复乘。原抗瞬间秒杀保护保持。

每个首领有普通攻击、落点/扇形/环形三种主动攻势及元素防御/强化机制。木首领回血与毒藤、水首领冰盾/召唤/减速、土首领岩盾与震荡、金火首领短暂狂暴或冲锋。主动高伤害预警至少2.6秒，太初至少3.2秒，技能间隔至少6.5秒；召唤数量有限，控制带间隔，可走位应对。

新原创图集包含十位独立首领：古树、熔岩战将、冰霜海蛇、石巨人、金甲剑君、深渊灵巫、归墟龙王、九幽炎魔、太初神皇、星隙龟甲巨像。图像由内置 image_gen 生成，透明RGBA，保存在 `web/assets/bosses-v27.png`。完整生成提示词与技术边界见 `AI-ASSETS-v27.md`。运行时使用原有分层身体/腿部动作，加上呼吸、蓄力、冲击位移、五行光环与死亡淡出；第三形态有五曜羽翼、金色冠光和大法阵。

这是2.5D图集与粒子升级，不是完整3D骨骼模型或十套手工逐帧动画。没有复制《魔兽争霸》或《刀剑封魔录》的角色贴图。

## 4. 太初神皇三条生命

第9关最终首领及其回响都必须连续击败三次。首条生命基数1×，第一次复活2×，第二次复活4×；最大生命、基础攻击、防御一起翻倍，并恢复该条满血。攻速、移动、控制时长不随倍率无限翻倍。

前两次只持久保存复活阶段，不发金币/经验/装备/通关奖励、不增加最终击杀。复活有3秒保护与聚能光柱；第二条解锁更多范围落点，第三条解锁五行阵法、终极范围与独立光翼形态。第三次才经过原有统一奖励事务，标记通关与最终击杀、发材料并保存。主条与画面标签显示“第几条生命”，避免与历史刷新轮数混淆。

保存再载入保留当前条数、血量和基础倍率，切换角色不重置；只要有合法存活队员留在地图就保持。全部离开或倒下后清理护卫与临时状态、重置第一条满血。奖励写入失败会恢复原来正生命的首领和未结算存档，不出现负血活体、假通关或重复材料。

旧存档已经通关第9关的战绩保持，原最终首领永久封印。菜单 → 逐关旅图 → 首领回响，可对已通关高级地图挑战独立回响，继续刷材料；不重复首通救援与剧情奖励。太初回响也要完整打三条生命。

## 7. 旧存档与已修复边界

新版本使用V27正常键与每世界独立口令键，读取V26及旧版后迁移；原旧键保留。新增经济字段只补默认，不重造角色或宝石。保留V26宝石紧凑身份区间与槽内ID，不把镶嵌宝石同时放回可用库存。

# 五行纪 · 山海五行 V7.0.0

公开游戏：https://dragonking888866.github.io/5elements/?v=7.0.0

本次交付为网页版V7。公开下载页中的Android与iOS工程仍为V5，不包含V7新增功能。

## 现在怎么玩

- 默认被动迎击：站立或跟随时不会主动攻击。点击「进攻」、J、敌人或右键进攻移动，开始主动进攻。受到攻击后可向攻击者还击。驻守、跟随、普通移动和WASD跑步会停止主动进攻；菜单也有停止命令。
- 攻击有间隔，连续点击不能绕过。武器、靴子、贪狼、白虎牙等可以提高攻速；最低间隔0.18秒。
- Q/E/R释放技能，G防御，空格闪避，H药剂，F互动，V灵宠技能，T百级觉醒，Y召唤天极神兽。手机有独立进攻、灵兽与神兽按钮。
- 属性、装备、灵宠、宝石、合体与转职面板顶部可以直接切换已招募角色。未招募角色不可选；面板切换不关闭当前整备流程。
- 回城需要1张卷轴。80金币可在各地图入口商店购买，战斗也会掉落。地图菜单、实地回城门和首领奖励页均不能绕过消耗。全队战败救援保留10%金币损失，不消耗卷轴。首次迁移赠2张。

## 统一五行

金→水→木→火→土→金相生；金克木、木克土、水克火、火克金、土克水。五行关系参考[故宫博物院的相生相克说明](https://www.dpm.org.cn/lemmas/244166.html)。天干名称参考[十干](https://www.dpm.org.cn/lemmas/240370.html)。所有伤害、概率与灵时增益均为游戏设计。

英雄、怪物、首领、六部位装备、灵宠和宝石均有五行。玩家克制敌人时造成130%基础伤害；被敌人克制时65%；相生关系112%；同气100%。怪物打玩家也按方向判定。护甲、护盾、格挡与首领减伤在此之外继续生效。

装备、骑宠和宝石与英雄的相生/同气关系提高整体共鸣，相克会略降共鸣。属性面板列出五行、共鸣、灵时加成和实际攻击间隔。灵宠技能按灵宠元素，天极神兽按宝石元素造成伤害。

灵时每180秒推进一格，循环十天干、十二地支和八卦。英雄与天干同属性获得2%生命、攻击、法术增益，与卦象同属性再加1%。宝石或灵宠合成材料包含当令元素时，成功率加1.5个百分点。该系统为虚构游戏时序，不使用现实日期预测。

## 灵宠与怪物

灵宠共39种，保留旧宠物ID，新增毕方、泽兽、青丘九尾、龙马、夔牛、天马、玉兔、旋龟、翼狮、古龙、羽蛇、灵狼、山魈、幻梦蝶、麒麟、驳兽、灵鼋、双首龙、金凰和星鲸。20类新怪物与首领包括邪修、骸卫、怨灵、妖僧、蝎妖、石像鬼、九首蛇、骨龙、巨螳、龙龟、火麟和雷鹏。

空中灵宠振翅、滑翔、浮游，具有离地高度和投影；地面灵宠行走、爬行、蹦跃或踏步。骑手随鞍点移动，灵宠有喷息、扑击与灵能技能。画面以原创立体插画图集、分层动作、深度遮挡和阴影朝3D观感优化，当前属于2.5D，没有完整可旋转3D场景。

灵宠包裹上限100只，每只独立保存；重复收集保留个体。每位英雄最多骑一只。契约商店按章节解锁新种类，战斗和合体也能发现新灵兽。

合体要求不同种类且双方10级以上，费用250金币。同气基础58%、相生70%、相克28%，再加幸运×0.35个百分点、双方较低融合星数×2个百分点及灵时加成，上限96%。幸运上限80。

成功消耗双方，新灵宠等级为平均值向下取整，最多3星；结果有元素偏好并可能出现意外变异。失败消耗材料二，材料一降1级并清空经验；被消耗宠物自动解除骑乘。确认页先显示概率与损失。成功后的稀有率为7%+幸运×0.35个百分点，相生额外5个百分点，上限50%。

## 十级宝石

共18类：赤焰石、沧月石、碧生石、天运石、鸡血石、田黄石、蓝金石、月光石、贪狼、破军、七杀、天罡、紫薇、青龙印、朱雀羽、玄武玉、白虎牙、麒麟珀。

两枚同级宝石合成一枚高一级，最高10级。同种保留名称；不同种类会在两种材料所属元素的候选中随机蜕变。相生比同气更容易，相克更难；幸运和灵时提高概率。基础成功率为同气94%、相生98%、相克58%，每高一级材料降低3.5个百分点，幸运每点加0.15个百分点，最高99%。费用为同种40×材料等级²金币，混合55×材料等级²金币。

成功消耗两枚材料和费用，得到高一级宝石；失败保留材料一，消耗材料二与全部费用。满堆叠或材料不足时不扣费。确认界面明确列出结果范围与概率。

商店只卖1、2级，妖兽和首领按五行掉落低级宝石。3—10级必须合成。只用1级材料、完全不失败的理论情况下，10级也需要512枚1级材料；失败会增加消耗。

武器有两个孔，替换、取下免费并归还旧宝石。宝石提升生命、攻击、智力、护甲、暴击、汲取、幸运或攻速，效果随等级提高。7级以上有强化粒子，9—10级增加金色环身光效。武器镶嵌10级宝石后，可召唤对应五行的白虎、青龙、玄武、朱雀或麒麟：60法力、90秒冷却，有即时范围伤害与12秒持续震击。切图或卸下天极宝石会结束持续召唤。

## 验证与工程

30项综合行为检查与20项独立模块检查通过，覆盖五行伤害单次计算、所有回城路径、被动反击、攻击间隔、面板实际角色按钮、合成成功失败扣除、十级召唤、地图隔离、空地动画以及原有地图/技能/首领/转职回归。

运行：`node tests/integration.cjs`、`node tests/bestiary-v7.cjs`、`node tests/forge-module.cjs`。

浏览器验收包括手机844×390横屏尺寸、面板内切换、随机十级熔炼与神兽按钮。手机为浏览器尺寸模拟验收，未在实体手机测试。

`web/`是静态网站根目录。runtime.js由game、upgrade、expedition、conquest、sanctuary、wuxing-v7、forge-v7、bestiary-v7、boot-v7依次合并，只有boot-v7启动游戏。QA种子和验收按钮仅位于本地预览服务器，不包含在发布包中。

V7使用独立存档键并兼容读取V6及更早存档。旧存档键保留；角色、宠物与宝石ID保持兼容。游戏为单人RPG，各浏览器独立存档，可通过菜单导出备份。

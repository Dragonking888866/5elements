# 五行战记 V24：存档冲突修复

直接游玩：https://dragonking888866.github.io/5elements/?v=24.0.0

点击“继续正常远征”即可。普通远征与独立口令档继续分离，V23及更早正常存档会读入新键，旧键不删除。不要清除浏览器的网站数据。

本版针对“另一标签已更新存档”导致开箱、属性加点、天赋学习和宝石熔炼一起被拦截的问题。

- 同一存档仅一个页面拥有写入权；其他页面暂停自动保存与结算。
- 使用最后一次核验保存的快照检查冲突，不再把实时对象的修订号当作提交基线。
- 初始化、自动保存、模拟结算和按钮操作使用同一 Web Lock 队列。
- 被接管页面可点击“在此页继续最新进度”，无需返回标题，接续时在锁内读取最新内容。
- 每次保存仍保留数据校验、前一快照备份、比较后写入与回读检查；写入失败仍回滚交易。

测试：329项（315项历史回归＋14项双页面/异步锁测试）。浏览器实际检查桌面、844×390、390×844和568×320，含正常继续、开箱、加点、天赋、连续熔炼及同页接续。详见 QA-v24.json。没有物理手机或 Safari 认证。

运行测试：`node tests/release-v24.cjs`
重新构建：`node build.cjs`

主要文件：ownership-v24.js、state-v10.js、session-v23.js、economy-v17.js、single-player-v16.js、recovery-v22.js、game.js、build.cjs、index.html、sw.js 与 tests/。

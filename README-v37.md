# 五行战记 V37 · 六灵契约

直接游戏：https://dragonking888866.github.io/5elements/?v=37.0.0

青禾营地 → 五行灵宠阁 → 点商品的「选择数量 / 批量购买」：1、5、10、50、自定义、MAX。每种灵宠沿用每天100只库存限制，普通灵宠库1000格。MAX受金币（含原有储备）、库存、空位和解锁条件约束。购买后继续购买、查看灵宠库或直接进入融合。

灵宠阁 → 支援名册，或原来的任务/支援管理入口：查看六名现有支援的新形象、大图、技能、招募条件与原创小传。点详情的待机/移动/攻击/支援可看动作。仍只可上阵两位支援；它们不属于普通灵宠融合或究极池。

原存档直接继续，ID、技能、等级、经验和上阵状态不重置。跨设备先导出存档。

本地：在web目录使用Python HTTP服务器，通过http地址打开；修改模块后在本目录运行node build.cjs。回归：node tests/release-v37.cjs。

手机适配已在390×844、844×390浏览器视口验证；实体手机的触摸、发热和内存还需真机测试。

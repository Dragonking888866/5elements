# 五行战记 V38 · 万象灵威

正式入口：https://dragonking888866.github.io/5elements/?v=38.0.0

继续原存档即可。电脑按 V 释放灵兽技；手机点「更多战斗操作 → 灵兽技」。菜单的画质设置中可以调整精细度、透明度与演出规模；默认开启低帧率自动保护。

本版新增 `pet-skills-v38.js`（统一技能调度与真实命中）、`pet-render-v38.js`（元素演出与画质预算）、`pet-materials-v38.js`（缓存粒子材质与十兽专属演出）。原英雄、装备、灵兽精灵、融合池、资产 ID 和存档键保持兼容。

七品质技能半径为 48、72、104、148、205、280、360 世界单位。混沌祖兽为最高档的 1.1 倍。半径控制实际命中范围；画质与透明度不影响伤害。普通宠物原有主目标伤害和冷却公式保留，究极灵兽保留各自治疗、护盾、削甲、束缚、打断和灼烧能力，改为蓄力与弹道结束后结算。

主要演出：水压喷流、浪峰与潮涡；多层火焰和凤凰火雨；折射冰晶和霜雾；体积感风柱与风刃；金刃连击、雷弧与虎爪斩痕；岩刺、断层与山岳守护。十兽各有独立演出分支，混沌祖兽保留五行连击。

本地构建：`node build.cjs`；完整回归：`node tests/release-v38.cjs`。本交付保留 `web/` 目录结构；仓库根目录发布构建使用同一模块列表。

本机浏览器验收：`python tests/ui/serve38.py`，打开 `http://127.0.0.1:8738/qa.html`；脚本只允许本机隔离来源，不要在正式网址运行。

运行截图、关键帧、录像与浏览器性能记录见 `验收/`。具体测试与限制见 `V38验收报告.md`。这是现有 Canvas 2.5D 渲染的升级，不包含真实流体模拟或 3D 体积光。

# 五行战记 V21 · 七星铸魂

直接游玩：https://dragonking888866.github.io/5elements/?v=21.0.0

电脑点击主画面「宝石」，手机点击「菜单 → 宝石」或「三石 / 五行炉」。商店、包裹、熔炼、五行神炉和镶嵌在同一导航中切换。

## 1. 统一分级与旧存档

宝石只有七档核心品质：**普通 → 精品 → 稀有 → 史诗 → 传说 → 神话 → 极其稀有**。所有正式入口的名称、图标、边框、商店、筛选、排序、熔炼和镶嵌都按这套品质显示。角色与装备自身的等级仍照常显示。

内部保留旧字段作为存档编码和传承灵蕴，不再作为第二条可升级的宝石等级轴。旧宝石按原品质及旧灵蕴取较高的品质映射，保持原始类型、数量、保护状态、镶嵌位置和已有灵蕴；基础和百分比加成都不会因迁移降低。不同旧堆叠具有传承标记，防止合并后超出9999枚上限而丢失物品。旧版已镶嵌宝石仍可准确拆回原堆叠。

正常存档使用 `wuxing-chronicles-v21`，可回退读取V20及更早版本。原正常V20键保留。正常远征与独立口令档继续分开。旧批量任务保留已完成的统计，新版本不自动续扣旧批次，需要按新规则重新选择目标。

## 2. 清晰的三石升品规则

- 三枚同种、同品质宝石：成功得到一枚同种、下一品质宝石。
- 三枚异种、同品质宝石：须命中公开配方，目标物种固定，仍只升一品质。
- 品质不同显示「品质不同，无法熔炼！」，按钮禁用，底层也拒绝扣款。
- 极其稀有不能继续普通熔炼。神石、锁定、收藏和绑定材料受保护。
- 正常失败完整保留第一槽主石，消耗第二、三槽两枚副石和预览费用。三槽使用同一堆叠时，失败从该堆叠只扣两枚。
- 成功消耗三枚材料和费用，生成一枚真实产物。没有新增残渣或碎片货币。

同种升品基础规则如下。最终概率还受全队共享幸运、灵时、失败保护、概率上限及实际装备的五行神石影响，以界面计算为准；异种配方另有公开配方附加费用和进阶要求。

| 材料品质 → 目标品质 | 基础成功率 | 金币 | 灵铁 | 灵焰 | 星核 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 普通 → 精品 | 100% | 120 | 0 | 0 | 0 |
| 精品 → 稀有 | 86% | 700 | 4 | 0 | 0 |
| 稀有 → 史诗 | 70% | 4,200 | 18 | 0 | 0 |
| 史诗 → 传说 | 52% | 24,000 | 75 | 0 | 0 |
| 传说 → 神话 | 32% | 145,000 | 260 | 3 | 0 |
| 神话 → 极其稀有 | 15% | 850,000 | 850 | 12 | 1 |

三石的五行关系共同参与配方概率计算，材料顺序不改变概率和产物。失败保护每次增加0.5个百分点，最多增加3.5个百分点，成功后清零。

本作目前是本地单人游戏，幸运为本存档的全队共享值。当前装备神石且存活的主持英雄炼制目标传说以上的宝石时，概率至少70%；这是保底，并非额外加70个百分点。独立口令体验的100%与免资源效果按真实启用状态列出，无法绕过材料品质和最高品质限制。

批量模式按品质目标逐次结算，可保留每堆指定数量，并支持暂停和恢复。高品质批量须确认，关闭或切换面板会暂停。汇总包含金币、灵铁、灵焰和星核。

## 3. 成功、失败与高级演出

熔炉显示三枚投入材料、目标大图、目标品质、全部属性、醒目的真实概率和四类资源成本。概率按80%、50%、20%分界显示绿、金、橙、红四种颜色。手机竖屏顶部另有概率或错误提示，无需向下翻找。

成功演出包括三石蓄能、元素能量汇聚、中央晶体升起、品质色光柱、符文与粒子爆发。传说、神话、极其稀有增加光柱和星芒，最长约4.2秒。结果明确展示新宝石名称、品质、属性、数量和真实消耗。

失败使用黯淡、碎裂阵环及红色结果，展示完整保留的主石和实际损失。启用游戏音效后会播放对应成败音效。演出可跳过、确认进包裹、继续熔炼或返回；最近结果刷新后仍可回看。

产物、损失和结果回执在同一笔持久化交易中保存，动画只读取已保存结果。重复点击、跳过、关闭和回看不会重复扣款。保存失败会回滚，不能出现画面成功而背包没有产物的情况。

画布像素比上限2，桌面最多30fps、手机最多24fps，粒子数量有上限；停留结果后降频，退出取消动画，旧回调不能重启。尊重系统减少动态效果设置。

## 4. 高级属性与实际战斗

| 五行 | 高级方向 | 实际接入 |
| --- | --- | --- |
| 金 | 攻速、暴击伤害、本系伤害、破除防御 | 普通攻击间隔和暴击倍率；敌人防御阶段的穿透计算 |
| 木 | 生命恢复、治疗效果、汲取 | 按时间回血；命中实际造成伤害后恢复生命 |
| 水 | 技能冷却、终极额外冷却、回蓝、控制 | 技能实际冷却与当前冷却重算；持续回蓝；水系技能控制时长 |
| 火 | 技能伤害、范围、灼烧领域系数 | 技能伤害计算、范围选择；火系职业持续领域伤害 |
| 土 | 护盾强度、本系抗性、减伤 | 实际护盾数值和受到伤害的计算 |

复合石的五行词条按其元素集合分摊，形成兼顾多个方向的选择。武器贡献100%，其他装备50%，觉醒灵台65%。高级加成由同一套属性表生成说明，并进入原有角色、技能、伤害、治疗及控制计算，不是仅在详情页展示数字。

极其稀有品质的常规宝石还提供300范围本系伤害+3%的共鸣光环，同类不叠加；镶在武器后可按Y召唤元素神兽。五行神石保留原有本体去重、光环与周期护盾逻辑。

主要最终上限：技能冷却40%，普通与终极合并冷却最多40%；攻速系数3倍且攻击间隔不低于0.18秒；汲取系数30%；每秒最大生命恢复3%；每秒最大法力恢复2.5%；暴击率70%、暴击伤害倍率3.2；本系抗性30%、减伤30%；护盾增强100%。治疗加成仍受原有60%上限约束，实际回复会遵循现有治疗修正与最大生命限制。每个技能也保留独立最短冷却。

## 5. 商店、包裹、镶嵌

普通和精品常备，真实通关前四关且解封五位英雄后开放稀有货架；史诗以上主要由熔炼或强敌掉落获得。神石由五行神炉炼制。商店支持品质、五行、名称和价格筛选，以及自定义购买数量。

宝石详情列出全部属性、拥有数量、已镶嵌数量、是否可熔炼、保护状态和武器换入预览。包裹与材料选择器分页，按品质及灵蕴强度排序。镶嵌与拆下免费，保留旧石，提供真实前后属性对比及镶嵌光效。替换或拆下后，当前生命和法力立即限制在新上限内；保存失败不会因此改变当前生命。

五行神炉需要五枚极其稀有单元素宝石，五行各一。成功生成五行神石；失败保留五枚宝石，仅消耗预览中的催化资源。原有首领战绩、英雄解封、进阶、冷却和成本递增要求继续生效。

## 6. 实现模块

- `web/gems-core-v21.js`：统一品质、迁移与传承堆叠、升品、配方、真实概率、资源结算、回执、存档校验、神炉与批量目标。
- `web/gems-combat-v21.js`：品质对应基础与策略属性、五行倾向、统一上限、非叠加共鸣光环、属性说明及武器流光。
- `web/gems-fx-v21.js`：晶体模型、蓄能/汇聚/成败演出及动画生命周期。
- `web/gems-ui-v21.js`、`web/gems-v21.css`：熔炉、结果、材料选择器、商店、背包、详情、镶嵌、手机与电脑布局、原入口及窗口路由。
- `web/combat-v18.js`：在原有装备属性通道中只计一次宝石策略词条。
- `web/furnaces-v17.js`：批量汇总完整记录高阶催化资源。
- `web/atelier-v17.js`：附魔材料门槛改为品质表达。
- `web/game.js`、`web/balance-v17.js`、`web/economy-v17.js`：版本键、旧档回退与独立口令分支兼容。
- `web/single-player-v16.js`、`web/developer-sandbox15.js`：样本授予与帮助使用七品质。
- `web/boot-v10.js`、`web/panels-v10.js`、`web/forge-v7.js`：指南、历史显示和神兽提示统一；角色与装备自己的等级不受影响。
- `web/index.html`、`web/sw.js`、`build.cjs`等：版本、缓存与61个公共模块整合。
- `tests/release-v21.cjs`、`tests/stability-v21.cjs`及测试夹具：新规则、迁移、交互、战斗、持续运行回归。

## 8. 运行与后续平衡

构建：`node build.cjs`。检查：`node tests/release-v21.cjs`。源码包通过静态服务器提供 `web/`，例如 `python -m http.server 8080 --directory web`。GitHub Pages仓库将 `web/` 内容放在根目录，仓库中的测试与构建路径已调整。

需要继续观察：神话/极其稀有材料的长期获取速度、不同职业两孔配装的收益、共鸣光环与原神石光环的组合，以及高阶Boss下的恢复和控制收益。当前数值和功能测试不代表完整普通装备通关平衡已验收。实体Android、iPhone和原生Safari的触摸与性能仍待实测。
